# 律聚人 UI 原型 v4.0「人民币双色系 · 玻璃拟态 · 简约」

单文件全量功能原型：**一个 `index.html` 内嵌全部 CSS / 原生 JS**，包含产品三端（用户端 App / 律师端 App / Web 运营后台）共 **39 个业务视图 + 1 个导航中枢**与全流程交互，双击即可在浏览器体验，零外部依赖（无 CDN / 框架 / 图标库 / 图片）。

> v4.4（2026-10-22）：**产品扩展批视图**——快速1对1解答（律师抢单报价·价格不公布·≤30min·双边评分·联系方式开关）、批量诉讼拼团（同司团：同类型×同公司）、找律师与非诉小单货架（律师自主定价服务商品）三业务全端入口（对应 PRD 2026-10-22 增补/04 v1.13/C7/C8/B4，施工排期 M3.5 ⚠）。

## 打开方式

直接用浏览器打开 `index.html`；或从仓库根目录：

```
start prototype/index.html   # Windows
```

校验完整性（改过页面后必须跑）：

```
cd prototype && node tools/check.js
```

## 整体架构（3 行）

1. 单 HTML 内嵌 CSS / 原生 JS，`VIEWS` 视图注册表 + `go()` 路由驱动三端切换（无刷新跳转 · 淡入过渡）；顶栏 seg 切换端，App 端渲染 390 宽手机框，后台渲染 sidebar 布局。
2. 全部数据为内置虚构 Mock（`DB` 对象，跨端共享同一份事实）：报名、支付、成团、接单、草稿发送等操作直接改内存状态并重渲染，对应端同步可见。
3. 图表为运行时生成的手绘 SVG（折线 / 柱状 / 环形 / 漏斗），图标为内置细线 stroke-1.5 图标库，弹层 / Toast / 抽屉 / 底部面板均为原生实现。

## 设计体系 v4.0

- **主色系（一元纸币 · 橄榄绿，约 90% 面积）**：底 `#F4F6F1` 米白绿 · 主色 `#3E5C3A` · 苔绿 `#6B8E5A` / 浅灰绿 `#A8B89B` · 文字 `#2C3E28` / `#7A8B74` · 高光 `#C9D6C0`
- **点缀色（百元纸币 · 豆沙红，≤10%）**：`#C25E5E` / 淡粉 `#E8C4C4`。只用于极小面积：单张焦点卡（一组卡中仅 1 张）、价格数字、主按钮、危险/超阈状态、图表焦点数据条；严禁大面积铺色、红绿五五开
- **玻璃拟态**：卡片 `rgba(255,255,255,.5)` + `backdrop-filter: blur(20px)` + 1px 半透明白边 + 16px 圆角；点缀卡 `rgba(194,94,94,.15)` 红玻璃；背景为低饱和橄榄绿圆形光晕漂浮，右上角极少量红色光晕呼应
- 图标：内置细线 SVG（stroke 1.5）；字体：系统无衬线栈；全页无深色、无外链资源

## 关键交互

- 用户端：**双维度选择框架（「应用做全套」口径——城市选择器 12 城全集可选 + 垂直选择器 4 垂直全集可选，不设客户端门槛；无供给维度展示空态与引导，供给开通=运营侧；2026-10-17 D-BP8 提前）**；报名支付（实名闸口 → 积分抵扣 ≤50% → 训练授权可拒绝 → 快照价）；发起拼团向导（选律师 → 锁时段 → 子范围算分摊 → 问题树标签，携带当前城市与垂直）；**批量同司团模式（向导切换「批量诉讼 · 同司团」→ 填用人单位 → 加入者同司声明规范化校验弹层 → 成员脱敏）**；**快速1对1解答（发单：标签+沟通偏好+联系方式明示/隐藏 → 我的快速单：报价对比[金额仅发单人可见] → 选定支付 → 30 分钟会话演示 → 双边评分弹层）**；**找律师目录（城市×垂直筛选 + 货架数/快速单标识 → 主页货架购买弹层 → 我的服务单确认完成）**；**发起拼团入口强化：FAB 悬浮主按钮 + 发现页 CTA 卡 + 首页三宫格快捷入口**；房间 @Agent/@律师 提问与自动回复；申请 1对1（类型 × 方式 × 价目矩阵）；改期 / 取消（规则提示）/ 导出聊天记录 / 匿名四维评价；训练授权撤回（物理删除链路说明）；律师实力档案（主页档案 + 列表卡片实力摘要）
- 律师端：**发起开团入口强化：FAB 悬浮主按钮 + 工作台顶部主按钮**；时间表三态（空闲 / 已占用 / 已锁定）点选开团；开团配置默认值可改（仅本次有效）；**接单大厅三段（拼团指定 12h 倒计时 · 快速单报价[金额不公布提示+报价表单] · 同司团响应[公司锚定+材料核验提示]）**；**非诉小单货架配置（新建/编辑/上下架 · 防错价 ¥50-5,000 · 版本化 v+1）**；**Agent 草稿气泡**：发送（以律师名义上屏 + 审查日志）/ 修改后发送 / 丢弃，采用率实时更新；价格修改三档规则演示（涨价 -5 / ≤10% -15 / >10% -30 停接 3 天）；1对1 价目区间校验（文字 50-300 / 音视频 100-500）；实力档案配置（资质字段只读 · 自愿字段可编辑）
- 后台：看板 SVG 图表与资损不变量巡检；资质审核通过 / 退回补充；在营律师实力档案查看 / 下架 / 恢复（LawyerProfileTakedown 联动演示）；房间只读监控 + 截图留证 + 介入终止（双人复核）；工单退款审批与 HOLD 释放；词库增删与人审队列；撮合站内信引导；规则版本公示；录音调取双人复核；调度 job 全集
