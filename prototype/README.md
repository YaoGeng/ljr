## 3. 设计规范（v3.0 纸币绿 · 玻璃拟态 · 简约）

v3.0 为**全面重设计**：以 PRD 与功能模块文档为输入重新设计全部 39 页，而非在旧稿上换肤。色彩取自 50 元人民币纸币绿。

| 项 | 规范 |
|---|---|
| 纸币绿 `#2A7057` 系 | 主色（50 元券色系推演）：主按钮、主 CTA、选中态、进度、hero、侧栏 |
| 印章红 `#C14E3A` | **只用于**：价格、已成团印章、危险/超阈状态（签名组件） |
| 币金 `#A67C16` | 积分、信用分 |
| 米白 `#F4F3EA` | 桌面/页面底；卡片=磨砂玻璃白（半透明 + backdrop 虚化 + 大圆角 + 柔绿投影） |
| 标题字体 | 宋体系衬线（Songti SC / STSong / SimSun），仅用于标题、品牌、印章、价格 |
| 正文 | 系统无衬线（PingFang SC / Microsoft YaHei） |
| 签名组件 | 已成团圆形印章（旋转 9°）、Agent 草稿气泡（"AI 辅助 · 仅供参考"、仅律师可见）、成团进度条 |
| 合规表达 | Agent 永不直发公屏；缺席/取消/改价规则在对应屏显著提示；资金"不过平台账户"表述一致 |

> 历史：v1.0–v1.1 为「契约与印章」墨蓝 + 朱红主题；v2.0（2026-10-14）按参考稿迁移为薄荷绿玻璃拟态（仅改令牌值）；v3.0（2026-10-14）按用户指示不看历史稿，以 PRD/功能模块为输入全面重设计，色系改为 50 元人民币纸币绿，界面简约化，共享样式表（app.css/admin.css）与全部页面同步重写。

## 4. 交互说明

- 原型为静态 HTML + 少量原生 JS（弹层开合、标签切换），无框架、无构建、无外链，直接双击打开即可。
- 页面间通过真实 `<a href>` 跳转，可按主链路走查：u01→u02→u03→u06→u07→u08→u11→（开场）u09→u10→u12；律师链路 l01→l07→l04→l03→l09；后台链路 a01→a02→a03→a04→a05→a06→a07。
- App 屏以 390×844 手机框呈现，桌面居中；后台为 ≥1280px 桌面布局。

## 5. 样例数据说明

全部数据为虚构，供原型演示：律师张明远/李慧敏/王振宇/陈晓薇（律所均为虚构）；用户周女士/吴先生/郑女士；金额、信用分、指标数字均为演示值，规则数字（宽限 5 分钟、70/30 分配、积分 100:1、抵扣 ≤50%、改价三档、12h 响应、3 日审核 SLA、公示 ≥7 日）与 PRD/模块文档一致。

**时间口径（静态原型的多时点说明）**：浏览与配置类屏幕（u02/u03/u05、l02/l04/l07、后台 a01–a04/a06–a14）锚定 2026-10-13（周二）白天；房间直播类屏幕（u09/l09）与监控（a05）锚定 10-16（周五）20:32 同一时刻；评价（u12）锚定该场结束后。同一场次由此呈现「待开始 → 进行中 → 已结束」的完整生命周期。
