# LJ 合规红线（lj-compliance-guards）

> 事实源：docs/02-架构设计.md（v2.1）§1.3（关键约束）、§4.6（Agent 草稿管线）、§5.2（存储与合规）、§6（安全风控合规表）。
> 本技能与架构文档修订**同 PR 更新**。合规边界以 PRD §14 为上游，架构为落地口径。

## 触发时机

agent 改 payment、settlement、agent-assist（LLM/草稿/脱敏）代码，或设计与留存、授权、免责、供应商接入相关的任何流程时自动装载。起草用户协议/隐私政策/审核 SOP 时配合运营侧文档使用（PRD §14）。

## 红线清单（逐条可执行，违反即 BLOCKER）

### 1. 资金不过平台账户（架构 §1.3-1）

- 所有资金走持牌支付机构分账（微信电商收付通/支付宝直联分账）。
- 平台不碰资金、不做资金中转、不自收任何形式的保证金。
- 涉及平台侧「收钱」的设计（保证金、缺席分成）一律落在支付机构侧托管账户，平台仅持指令权与台账。
- **生产支付通道（证书、密钥、回调验签配置）禁止封装为 agent 可调用工具**（架构 §4.3 限定 + 技能指南 §7-4）。

### 2. 留存 3 年（架构 §5.2 合规 R2、§1.2）

- messages 热存 PG（90 天）→ 冷存 OSS，**自服务（交易）完成之日起不少于 3 年**（电商法 §31 锚定；法定留存义务构成 PIPL §13(三) 处理基础）。
- 1对1 录音录像：OSS 合规 bucket（WORM/版本锁定），哈希上链存证，留存 ≥3 年；仅合规角色经审批调取（审计）+ 本人调取通道（PIPL §45）。
- 到期处置：OSS 生命周期规则到期自动删除或匿名化转统计；删除动作入审计。

### 3. 单独同意（架构 §5.2 合规 R3/R6）

- 训练数据三层授权：① 首次成团/支付流程内**独立授权页**（可拒绝，拒绝不影响拼单与房间功能，仅该房间消息不进训练语料库）；② consents 表记录（scope=training）+ 策略版本；③ 设置中心可撤回，撤回后未训练样本经 source_msg_id 反查物理删除。
- 实名单独同意：consents 记录（scope=realname）。
- 1对1 会话录制须双方 recording_consent 信令才启动云端录制（未确认仅不开录制）；拼单房间语音/视频默认不录制。
- 脱敏输出定性为**去标识化数据（仍属个人信息）**：仅限平台内部训练、不出库不共享；达到匿名化标准前不得对外提供语料（架构 §5.2、§8 V3）。

### 4. AI 不出庭（架构 §1.3-4、§4.6）

- Agent 输出**永不直接进入房间公屏**，必须经律师审查——草稿管线与消息发送链路**物理隔离**（无共享写入点）。
- 发送动作 = 把草稿内容作为律师消息提交，经正常消息风控后再入房间。
- Agent 草稿仅律师可见且带「AI 辅助，仅供参考」标记（不构成法律意见）；@Agent 消息只生成非法律意见类自动响应，法律实质内容一律由律师名义发送。
- LLM 故障降级显式态：律师端明确显示「AI 辅助不可用」，不阻塞律师手打回复。
- 敏感话术硬拦（承诺结果/包赢类）不生成草稿。

### 5. LLM 供应商硬约束（架构 §1.3-5、§4.5 技能指南）

- 仅允许境内运营、数据不出境、API 输入不留存且不用于供应商训练的合规供应商（通义/智谱/DeepSeek 等，架构 §1.3-5 白名单口径）。
- 采购前签署 DPA/委托处理协议；供应商列入准入合规审查清单；切换供应商需重过合规检查（含出境评估触发条件）。
- **用户原文进 LLM 前必须经过实时脱敏层**（NER+规则：姓名/证件/电话/地址→占位符，纳入 8s 预算，架构 §4.6）——见 lj-data-security。

### 6. 边界披露与规则治理（架构 §6 合规边界/规则治理行）

- 房间须知为可配置内容块，含「法律意见由执业律师作出、平台提供信息技术撮合」用户侧披露。
- 缺席扣费规则在支付前显著确认。
- 规则版本化 + 公示 ≥7 日 + 行为时快照 + App 规则中心信息页（架构 §4.3、§6 合规 R11）。
- 网安法 §47「停止传输+处置+记录+报告」流程入 ops 工单。

## 验收判据（可观察）

- 任何把 Agent 输出直接写向房间公屏消息表的代码路径 → BLOCKER。
- LLM 调用入参中出现未脱敏的用户原文（姓名/证件/电话/地址）→ BLOCKER。
- 平台账户收款/自收保证金的设计 → BLOCKER。
- 留存期配置 <3 年、或无到期处置作业 → BLOCKER。
- 训练语料入库未经 consents(scope=training) 校验 → BLOCKER。
