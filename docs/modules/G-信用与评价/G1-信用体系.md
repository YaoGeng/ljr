# G1 信用体系

> 域：G-信用与评价 ｜ 架构模块：credit ｜ V1 ｜ P0 ｜ 阶段：①
> 上游：C4/C6/D3/D4（信用事件源）、B2（锁滥用）、H1（实力档案虚假处置） ｜ 下游：C1/C3（入口校验限制令）、H1（公开档案信用分展示）、H4 ｜ 技能：P0六件套 + lj-domain-rules + lj-test-matrix

## 1. 职责与边界
- 做：CreditEvent 不可变流水+账户快照（唯一事实源）；规则表驱动（PRD §8.8 全表）；限制令发放与查询。
- 不做：入口拦截逻辑本体（各入口调查询）；规则公示（H7）。

## 2. 功能点
- 事件接入（全表行为→分值映射，规则表 rule_definitions 驱动、行为时快照版本）
- 限制令：限制拼单（多次缺席）/停接 3 天（降价>10%）/停接 7 天（连续 2 次取消缺席）/恶意改价停接
- 查询接口（本人+入口校验用；2026-10-16 增量：/credit/score 内部面供 H1 实力档案公开面聚合，仅出分数不出流水）

## 3. 领域模型
credit_accounts(owner_type varchar(8), owner_id bigint, score int NOT NULL DEFAULT 100,
  updated_at, PRIMARY KEY(owner_type, owner_id))
credit_events(id bigserial PK, owner_type, owner_id, action varchar(32) NOT NULL, delta int NOT NULL,
  rule_version int NOT NULL, ref_type varchar(16), ref_id bigint, created_at)   -- 不可变，仅 INSERT
credit_restrictions(id PK, owner_type, owner_id, kind varchar(24),  -- BAN_JOIN|BAN_PUBLISH|SUSPEND_TAKE_3D|SUSPEND_TAKE_7D
  until timestamptz, reason, created_at)
-- 失效机制：惰性判断（查询时比对 until <= now() 即失效，无需 I2 物化 job；I2 全集已声明排除 RESTRICTION_EXPIRE）
注：lawyer_profiles.credit_score 读缓存为规划项（唯一事实源=credit_accounts；当前以 /credit/score 查询面对外提供，identity.lawyer_profiles DDL 无该列）。

## 4. 关键流程
事件（at-least-once）→ 幂等（ref_type+ref_id+action 唯一）→ 规则表查分值（行为时版本）→ 流水+快照同事务 → 达阈值发限制令事件。
连续违规计数（30 天窗口）：取消/缺席 ≥2 → SUSPEND_TAKE_7D。

## 5. 接口契约
| GET | /credit/mine | - | {score, recent_events, restrictions[]} | - | 否
| GET | /credit/restrictions?owner= | 内部 | 活跃限制令 | - | 否
| GET | /credit/score?owner= | 内部 | {score} | - | 否（2026-10-16 增量，H1 实力档案消费）
| 内部 | EMIT_CREDIT_EVENT | {owner, action, ref} | - | - | 幂等键=ref+action

## 6. 领域事件
- 生产：CreditEventEmitted{...}；RestrictionIssued{owner, kind, until}（→C1/C3 入口拦截——限制令执行点仅开团/报名入口，资质审核面无拦截点）。
- 消费：LawyerRejected(Timeout)、PriceChangeApproved、AttendanceAdjudicated、SessionCancelled、SlotAbuseDetected、ReviewSubmitted、LawyerProfileTakedown（H1 实力档案虚假填写处置→信用扣分，2026-10-16 增量；扣分档位走规则表 H7 配置 ⚠）。

## 7. 业务规则（PRD §8.8 全表，规则表驱动）
用户：正常参与 +分；提前取消 轻微扣；2h 内取消 扣；缺席 重扣；多次缺席 限制发起/参与拼单
律师：取消≥24h -10；取消<24h -30；缺席 -50；拒绝/超时 C2B -5；连续 2 次取消/缺席 停接 7 天；涨价(在团) -5；降价≤10% -15；降价>10% -30+停接 3 天；恶意频繁改价 -20/停接
- R-01 信用分下限 0、上限开放；初始 100
- R-02 行为发生时快照适用规则版本（H7 联动）｜架构 §4.3
- R-03 事件不可变、可审计 ｜架构 §4.7

## 8. 非功能要求
- 事件消费幂等；入口校验查询 P95 ≤20ms（缓存活跃限制令 30s）。

## 9. AI 开发标准（本模块附加）
- TDD（lj-test-matrix）：全表行为×分值、连续 2 次窗口边界、幂等重放、限制令到期自动失效；
- 禁止：UPDATE credit_events；分值硬编码（规则表）。
