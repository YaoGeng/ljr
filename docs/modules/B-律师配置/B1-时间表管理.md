# B1 时间表管理

> 域：B-律师配置 ｜ 架构模块：schedule ｜ V1 ｜ P0 ｜ 阶段：①
> 上游：- ｜ 下游：B2（物化+加锁）、C1/C2（选段）、C5（改期选段） ｜ 技能：P0六件套 + lj-domain-rules

## 1. 职责与边界
- 做：按周重复的可预约时间段模板管理；单场时长（60/90/120min）；时间段状态视图（空闲/已占用/已锁定）；模板变更不影响已排期场次。
- 不做：具体场次时刻的锁定（B2）；场次创建（C1/C2）。

## 2. 功能点
- 模板 CRUD（weekday + start_time + duration，支持多段、按周重复）
- 物化入口：某日期的被选模板 → 计算具体 timestamptz（Asia/Shanghai）→ 交 B2 加锁
- 状态视图：日期 × 模板 → 空闲（无活跃锁）/ 已锁定（LOCKED）/ 已占用（OCCUPIED）

## 3. 领域模型
time_slot_templates(
  id bigserial PK, lawyer_id bigint NOT NULL,
  weekday smallint NOT NULL CHECK (weekday BETWEEN 0 AND 6),
  start_time time NOT NULL, duration_small smallint NOT NULL CHECK (duration_small IN (60,90,120)),
  enabled boolean NOT NULL DEFAULT true, created_at timestamptz
)
物化结果不落库（由 B2 的 slot_locks 承载具体时刻）。

## 4. 关键流程
- 物化算法：date + weekday 匹配 → slot_start = date AT TIME ZONE 'Asia/Shanghai' + start_time；DST 无影响（中国无夏令时）。
- 模板变更（禁用/修改）只影响未来的物化候选，已存在 slot_locks 的场次不受影响。

## 5. 接口契约
| 方法 | 路径 | 入参 | 出参 | 错误码 | 幂等
|---|---|---|---|---|---
| GET  | /lawyer/{id}/schedule | - | {templates[]} | - | 否
| PUT  | /lawyer/schedule | {templates[]} 全量替换 | {templates[]} | 400 INVALID | 幂等键=lawyer+version
| GET  | /lawyer/{id}/slots?from=&to= | 日期区间 | [{slot_start, status, ref}] | - | 否

## 6. 领域事件
- 生产：无（模板为本地配置）。
- 消费：SlotLocked/SlotReleased/SlotTtlExpired → 更新状态视图缓存。

## 7. 业务规则
- R-01 模板变更不影响已排期场次 ｜PRD §6.1/§7.2.2、架构 §4.2
- R-02 slot_start 一律具体场次 timestamptz，模板不参与唯一约束 ｜架构 §4.2/§5.1
- R-03 单场时长仅 60/90/120 三档 ｜PRD §6.1

## 8. 非功能要求
- 状态视图查询走 slot_locks 实时 join + Redis 缓存（60s）；律师端时间表页 P95 ≤300ms。

## 9. AI 开发标准（本模块附加）
- TDD：物化算法（跨周边界/月末/年初）、R-01 不变性；
- 禁止：把模板当具体时刻锁定（唯一约束在 B2 的 slot_locks 上）。

## 10. 验收清单
- [ ] 跨周边界物化正确（周日 23:30 + 60min）
- [ ] 禁用模板后已锁场次照常履约（R-01）
- [ ] 状态视图与 slot_locks 一致（并发下最终一致 ≤60s）
