# B4 非诉服务货架配置

> 域：B 律师配置｜架构模块：pricing（schema 归属=pricing）｜版本：V1.5（产品扩展批，PRD 2026-10-22 增补 §6.8/§7.2.10/§8.11）｜优先级：P1｜施工阶段：⑤（05 §7.5 M3.5-W1）
> 上下游：上游=A3a（律师过审才可配置）、B3（价格域先例）；下游=C8（服务单消费 item_snapshot）、H1（律师目录聚合货架数）、H4（货架指标）
> 必载技能：superpowers P0 六件套 + lj-domain-rules + lj-payment-invariants（定价面）

## 1. 职责与边界

- 律师配置非诉服务商品（套餐）：名称、内容清单（咨询/诉讼文书/证据收集指导/立案指导/程序指导/庭前培训等）、价格、交付方式（平台内会话/会话+文件）、完成时限承诺（可选 ⚠）、上下架。
- **律师自主定价**：平台仅做防错价区间校验（¥50-5,000，D24 拍板，配置化走 H7），不构成指导价——PRD §8.11 明示。
- 商品版本化：在售商品修改产生新版本；**不回写已购服务单**（快照哲学同 §4.3）。
- 不做：服务单交易与履约（C8 承载）；结算（F3）；内容合规审查执行（H5 词库对商品描述照常覆盖，本模块只调用）；跨域 join（目录聚合经 H1 查询面消费本模块导出面）。

## 2. 功能点清单

- 律师端：货架列表（在售/已下架）、新建/编辑套餐（内容清单多选+价格+交付方式+时限承诺）、上下架、版本记录查看。
- 用户端（经 C8/H1 展示）：律师主页货架区、找律师列表货架数标识——本模块只供数，不承载页面。
- 后台（H1 目录聚合）：货架数/在售状态只读聚合；违规商品下架（复用 LawyerProfileTakedown 同款处置链 ⚠ 随 H1 批定型）。

## 3. 领域模型（DDL 级）

```sql
lawyer_service_items (
  id            uuid PK,
  lawyer_id     uuid NOT NULL,            -- identity 律师 user id
  name          varchar(64) NOT NULL,     -- 套餐名
  contents      jsonb NOT NULL,           -- 内容清单标签数组（如 ["咨询","诉讼文书","立案指导"]）
  description   varchar(500),
  price         numeric(12,2) NOT NULL CHECK (price >= 0),   -- 金额禁 float
  delivery_mode varchar(16) NOT NULL DEFAULT 'CHAT',         -- CHAT | CHAT_FILE
  sla_hours     int,                      -- 完成时限承诺（小时，可空 ⚠）
  active        boolean NOT NULL DEFAULT true,
  version       int NOT NULL DEFAULT 1,
  created_at    timestamptz NOT NULL DEFAULT now(),
  updated_at    timestamptz NOT NULL
);
CREATE INDEX idx_service_items_lawyer ON lawyer_service_items(lawyer_id) WHERE active;
```

- 防错价区间校验为应用层规则（R-02），不落 CHECK（阈值配置化，走 H7 规则版本化）。
- 时间一律 timestamptz（Asia/Shanghai）；状态字段 active 布尔+version 整数，无独立状态机（上下架=active 翻转，守卫校验在售订单引用）。

## 4. 状态与关键流程

- 上下架：`active true→false` 随时可下架（不影响已购服务单，C8 按 snapshot 履约）；`false→true` 需通过 R-02 校验。
- 修改在售商品：`version+1`，旧版本行留痕（或同表 SCD：以 version 区分，active 唯一指向当前版本——施工取「单行+version 递增+更新前快照写入 audit log」最小形态，模块施工时定 ⚠ 不扩表）。
- 购买引用：C8 创建 service_orders 时**同事务读当前 active 行并固化 item_snapshot**（商品名/内容清单/价格/delivery_mode），此后本表变更与该订单无关。

## 7. 业务规则

- **R-01 上下架自由**：律师可随时下架；下架不影响已购服务单（C8 快照履约）。〔PRD §8.11〕
- **R-02 防错价校验**：price ∈ [50, 5000]（已拍板 D24，rule_key=service_item_price_range，配置化）——防误输非指导价；越界 422 E_PRICE_OUT_OF_RANGE。〔PRD §8.11〕
- **R-03 内容清单必填**：contents 至少 1 项，取值=平台内容标签全集（咨询/诉讼文书/证据收集指导/立案指导/程序指导/庭前培训/合同审查…，E3 配置包维度 ⚠ 起步用内置枚举）。〔PRD §7.2.10〕
- **R-04 版本化**：在售商品每次修改 version+1；已购订单以 item_snapshot 为准，不随版本变化。〔PRD §8.11；架构 §4.3〕
- **R-05 合规话术**：name/description 过 H5 行业违规词库（包赢/保证结果类硬拦），同步前置调用（同 D5 消息风控链路语义）。〔PRD §14.2〕

## 8. 非功能要求

- 律师端配置操作 P95 ≤300ms；公开货架读面可缓存（H1 目录聚合失效驱动）。
- 安全：仅过审律师可配置（403）；公开读面不返回律师内部字段。

## 9. AI 开发标准（本模块附加）

- 金额处理经 @ljr/shared Money 工具（NUMERIC 字符串，禁 parseFloat 裸算）；contents jsonb 读写定义 zod/type 契约入 shared。
- 公开读面与律师写面分控制器；admin 只读聚合经 H1（本模块不新增 admin 面）。
