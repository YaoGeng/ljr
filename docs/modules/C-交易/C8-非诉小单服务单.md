# C8 非诉小单服务单

> 域：C 交易｜架构模块：trade（主属）+ payment/settlement + fulfillment(D5) 复用｜版本：V1.5（产品扩展批，PRD 2026-10-22 增补 §6.8/§7.1.10/§8.11/§9.6）｜优先级：P1｜施工阶段：⑤（05 §7.5 M3.5-W1）
> 上下游：上游=B4（lawyer_service_items 快照源）、A2（实名闸口）、G1（限制令）；复用=F1（支付）、F2（退款）、F3（HOLD→SETTLED，ref_type 扩展）、D5（one_on_one 会话交付）、I3（文件交付）、I1/I2（通知/超时 job）、G2（双边评价）；下游=H3（取消协商工单）、H4（服务单指标）、H1（目录聚合）
> 必载技能：superpowers P0 六件套 + lj-domain-rules + lj-payment-invariants（资金面交叉审查强制）+ lj-test-matrix

## 1. 职责与边界

- 承载非诉小单的交易与履约编排：购买（B4 商品快照固化）→ 支付 → 律师接单 → 平台内会话交付 → 用户确认（/超时自动确认）→ HOLD → 结算。
- **快照铁律**：下单同事务固化 item_snapshot（名称/内容清单/价格/delivery_mode），B4 后续修改与本单无关。
- 结算复用 F3：服务单作为新 ref_type（service_order）进入既有 HOLD→SETTLED 链；**试运行期免服务费口径不变**（04 §8 #40）。
- 不做：商品配置（B4）；会话与消息本体（D5）；文件存储本体（I3）；出庭代理相关任何能力（合规红线，PRD §14.2）。

## 2. 功能点清单

- 用户端：律师主页货架购买、找律师入口（H1 目录）、我的服务单（状态/交付内容入口/确认/评价）、取消申请。
- 律师端：服务单待办（待接单/服务中/待确认）、接单、会话交付（文本+文件）、标记交付、拒单（=退款路径）、评用户入口。
- 后台：H3 工单分类扩展（服务单取消协商/交付争议）；H4 指标（接单超时率/交付确认时长/满意度）。

## 3. 领域模型（DDL 级，schema=trade）

```sql
service_orders (
  id             uuid PK,
  user_id        uuid NOT NULL,
  lawyer_id      uuid NOT NULL,
  item_id        uuid NOT NULL,          -- B4 商品（逻辑引用）
  item_snapshot  jsonb NOT NULL,         -- {name, contents, price, delivery_mode} 下单同事务固化
  price          numeric(12,2) NOT NULL CHECK (price > 0),
  status         varchar(24) NOT NULL,   -- 状态机经守卫，禁裸写
  conversation_id uuid,                  -- D5 会话（ACCEPTED 时创建）
  delivered_at   timestamptz,
  confirmed_at   timestamptz,
  cancel_reason  varchar(255),
  created_at     timestamptz NOT NULL DEFAULT now()
);
CREATE UNIQUE INDEX uq_service_orders_active_buyer
  ON service_orders(user_id) WHERE status IN ('CREATED','PAID');  -- 同一用户同时至多一个未接单在途（防误重复下单，语义同 B2 每用户锁 ⚠ 宽严可调）
```

## 4. 状态机与关键流程

```
CREATED(待支付) → PAID(待接单) → ACCEPTED(服务中) → DELIVERED(已交付待确认)
→ FINISHED(用户确认/72h 超时自动确认 ⚠) → [F3] HOLD(24h) → SETTLED
CREATED → CANCELLED(支付前放弃)
PAID → LAWYER_TIMEOUT(默认 24h ⚠ 未接单) → REFUNDED(全额)
PAID → CANCELLED → REFUNDED(接单前用户取消=全退)
ACCEPTED → CANCELLED → (协商一致退款 | 协商不成转 H3 工单裁决；已开始交付不退)
DELIVERED → REFUNDED 仅经 H3 工单裁决路径（正常流不退）
```

- 流程：购买（G1 校验+实名闸口+快照固化同事务）→ F1 支付（幂等键=svc:{order_id}；#40 直接成功口径）→ PAID 写 I2 接单超时 job → 律师接单（原子守卫：仅本律师+PAID）→ 同事务经 D5 导出面建 one_on_one 会话（复用 D6 同款会话创建事件 OneOnOneConversationCreated，ref=service_order）→ 会话内交付（文本/文件，风控链路同 D5）→ 律师标记 DELIVERED（写确认超时 job 72h ⚠）→ 用户确认/超时自动 FINISHED → F3 消费 ServiceOrderFinished 进 HOLD→SETTLED。
- 律师拒单：仅 PAID 态可拒，等同 LAWYER_TIMEOUT 路径（全额退款；连续拒单/超时按 §8.6 连续取消口径累计 ⚠ 计数锚=G1 事件）。

## 7. 业务规则

- **R-01 快照固化**：下单同事务固化 item_snapshot+price；B4 修改/下架不影响已购订单（404 仅拦新单）。〔PRD §8.11；架构 §4.3〕
- **R-02 接单超时**：PAID 持续 D_SVC_ACCEPT（24h，已拍板 D24）未接单 → 自动全额退款；连续超时/拒单累计按 §8.6 连续取消口径（2 次停接 7 天，计数锚=G1 事件）。〔PRD §8.11〕
- **R-03 取消分档**：接单前=全额退；接单后未交付=申请协商（一致→退；不成→H3 工单裁决）；交付后=不退（争议走工单）。〔PRD §8.11〕
- **R-04 确认超时**：DELIVERED 后 D_SVC_CONFIRM（72h，已拍板 D24）无买家动作 → 自动 FINISHED（auto=true）。〔PRD §8.11〕
- **R-05 平台内闭环**：交付与会话仅平台内（复用 §7.2.8 私聊限制+风控词库）；文件交付走 I3（大小/配额 ⚠ 随 I3 既有策略）。〔PRD §14.2〕
- **R-06 合规话术**：套餐描述与交付内容过 H5 行业违规词库（包赢/保证结果硬拦）；「全程陪跑」类定位=指导与陪同，禁代理承诺。〔PRD §14.2〕
- **R-07 结算**：FINISHED → F3 HOLD 24h → SETTLED 律所对公；试运行期免服务费（#40）；纠纷工单挂起 HOLD（复用既有挂起/恢复消费链）。〔PRD §9.5/§9.6〕

## 8. 非功能要求

- 购买/接单原子守卫并发安全；接单/确认 job 幂等回查（同 I2 全集语义，I2 目录新增 D_SVC_ACCEPT/D_SVC_CONFIRM 两型——施工时随 T0 契约冻结登记）。
- item_snapshot 含价格 NUMERIC 字符串；金额经 Money 工具，禁 float。
