# D3 到场与缺席判定

> 域：D-履约 ｜ 架构模块：fulfillment + RTC/IM（presence） ｜ V1 ｜ P0 ｜ 阶段：②
> 上游：D5（presence 事件）、D1（宽限结束/开房状态）、I2（判定 job） ｜ 下游：F3（70/30 分成依据）、F4（30% 积分分配）、G1（信用）、F2（不退费标记）、H1（准时到场率统计源） ｜ 技能：P0六件套 + lj-domain-rules + lj-test-matrix

## 1. 职责与边界
- 做：presence 事件幂等消费；宽限结束时点在场快照判定；normal/late/absent 三态；律师缺席前置校验。
- 不做：presence 采集（D5/RTC）；分成执行（F3/F4）；信用执行（G1）。

## 2. 功能点
- join/leave 事件 → attendances 写入（user_id + role + join_at）
- 判定：grace_end 时点在场快照（含 30-60s 抖动容忍窗口：判定时刻回看最近 60s 内有 join 记录即视为在场）
- late：宽限后 ≤15min 进入（旁听，不退费不重计时）；absent：>15min 或从未进入
- 律师缺席前置校验：room.open_fail_reason 非空或 RoomOpenFailed → 不判律师缺席（走 D4 平台取消）
- 到场统计查询面（准时到场率，口径=H4）供 H1 实力档案公开面聚合（2026-10-16 增量）

## 3. 领域模型
attendances(
  id bigserial PK, room_id bigint NOT NULL, user_id bigint NOT NULL, role varchar(8) NOT NULL,  -- user|lawyer
  first_join_at timestamptz, last_seen_at timestamptz,
  status varchar(12) NOT NULL,                 -- NORMAL|LATE|ABSENT
  adjudicated_at timestamptz, UNIQUE(room_id, user_id)
)

## 4. 判定流程（grace_end + 15min 两级 job）
job1（grace_end）：快照在场者 → NORMAL；律师在场且用户在场 → 房间 IN_SERVICE；全员缺席 → 通知 D1 平台取消。
job2（grace_end+15min）：期间进入者 → LATE（旁听）；仍未进入 → ABSENT（发事件）。
抖动容忍：判定时回看最近 60s presence 记录，断线重连 ≤60s 不误判。

## 5. 接口契约
| GET | /rooms/{id}/attendance | - | [{user_id, role, status, join_at}] | 403 NOT_PARTY | 否
| GET | /lawyer/attendance-stats?from=&to= | 内部（H1 实力档案聚合） | {samples, punctual_rate} | - | 否（2026-10-16 增量；口径=H4）
内部消费 presence MQ（D5 生产）；判定 job 内部触发。

## 6. 领域事件
- 生产：AttendanceAdjudicated{room_id, user_id, role, status}（→F3 分成、F4 积分、G1 缺席扣分）。
- 消费：PresenceJoined/PresenceLeft（D5）；GracePeriodEnded（D1）；ScheduleJobFired。

## 7. 业务规则
- R-01 宽限内进入=NORMAL；超宽限 ≤15min=LATE（旁听不退费不重计时）；>15min=ABSENT 费用不退 ｜PRD §8.5
- R-02 用户缺席费用：70% 律师 + 30% 平台积分发到场用户；占比分摊计算与取整公式由 F4 唯一定义（本模块仅发 AttendanceAdjudicated 事件，不实现金额计算）｜PRD §8.5
- R-03 缺席扣信用、多次缺席限制拼单（G1 规则）｜PRD §8.5/§8.8
- R-04 律师缺席判定前置校验开房成功；平台故障不扣律师 ｜架构 §4.9
- R-05 判定以宽限结束时点快照为准，30-60s 抖动容忍 ｜架构 §4.9

## 8. 非功能要求
- presence 事件消费幂等（重复 join 不双写）；判定 job 回查幂等（人工操作先到则无操作）。

## 9. AI 开发标准（本模块附加）
- TDD（lj-test-matrix）：15min 边界、抖动 45s/61s、律师开房失败不判缺席、占比分配计算（多人场景精确到分）；
- 禁止：用客户端心跳替代 join/leave 事件作判定源；absent 判定跳过开房校验。

- [ ] 30% 积分按支付占比分配金额复核（F4 桩）
