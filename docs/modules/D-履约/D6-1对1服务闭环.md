# D6 1对1 服务闭环

> 域：D-履约 ｜ 架构模块：fulfillment + payment ｜ V1 ｜ P0 ｜ 阶段：②
> 上游：D5（房间内申请/会话）、B3（1对1 价格）、A2（实名） ｜ 下游：F1（支付/退补）、F3（结算）、I2（超时/实结 job）、G1（15min 未付信用） ｜ 技能：P0六件套 + lj-payment-invariants + lj-domain-rules + lj-test-matrix

## 1. 职责与边界
- 做：申请→支付→会话创建→接单（N 分钟超时）→服务计量→实结（多退少补）→取消三档。
- 不做：消息/音视频（D5/RTC）；支付通道（F1）；结算分账（F3）。

## 2. 功能点
- 申请（服务类型：深度解答/文书修改/策略建议 × 方式：文本/语音/视频）
- 预付全额（按 B3 矩阵价）
- 接单超时 N ⚠ → 自动全额退款
- 计量：文字=实服务轮次（一轮=用户问+律师答）；语音/视频=RTC 时长回调 ÷15min 向上取整
- 实结：双方确认或 30min 默认 ⚠；多退（部分退款指令）/少补（补差单，用户 App 内确认支付，15min 未付按已服务比例结算+信用记录）
- 取消三档：开始前全退；开始后未满单位退 50%；接单超时自动退

## 3. 领域模型
one_on_one_orders(
  id bigserial PK, room_id bigint NOT NULL, conversation_id bigint NOT NULL,
  user_id bigint NOT NULL, lawyer_id bigint NOT NULL,
  service_type varchar(16) NOT NULL, mode varchar(8) NOT NULL,
  unit_price numeric(10,2) NOT NULL,           -- 文字=每轮；语音视频=每 15min
  prepaid numeric(12,2) NOT NULL,
  consumed_units int NOT NULL DEFAULT 0,       -- 文字=轮次；语音视频=15min 段数（向上取整）
  settle_amount numeric(12,2) NULL, refund_amount numeric(12,2) NULL,
  diff_order_id bigint NULL,                   -- 补差支付单
  status varchar(24) NOT NULL,                 -- 见状态机
  accept_deadline timestamptz, started_at timestamptz, finished_at timestamptz, settle_deadline timestamptz
)

## 4. 状态机
CREATED → PAID（预付全额；**此时写入 accept_deadline = paid_at + N**） → ACCEPTED（律师接单） → IN_SERVICE（started_at） → FINISHED → SETTLING → SETTLED
PAID →（paid_at+N 未接单，I2 OOO_ACCEPT_TIMEOUT 锦定 accept_deadline） LAWYER_TIMEOUT → REFUNDED
PAID/ACCEPTED → CANCELLED(三档) → REFUNDED/PARTIAL_REFUNDED
IN_SERVICE → FINISHED →（多退）REFUND_PARTIAL /（少补）DIFF_PENDING → SETTLED
守卫：实结 = unit_price × consumed_units（NUMERIC）；补差单未确认不扣款。

## 5. 接口契约
| POST | /one-on-one | {room_id, service_type, mode} | {order, payment_order} | 402 REALNAME / 400 PRICE_MISSING | 幂等键=user+room+type
| POST | /one-on-one/{id}/accept | - | {conversation_id} | 409 TIMEOUT | 幂等键=order
| POST | /one-on-one/{id}/finish | - | {consumed_units 声明} | 409 NOT_IN_SERVICE | 幂等键=order
| POST | /one-on-one/{id}/settle-confirm | - | {settle_amount} | 409 MISMATCH | 幂等键=order
| POST | /one-on-one/{id}/settle-diff/pay | - | {diff_payment_order} | 409 NOT_CONFIRMED | 幂等键=order
| POST | /one-on-one/{id}/cancel | - | {refund} | 409 NOT_CANCELLABLE | 幂等键=order

## 6. 领域事件
- 生产：OneOnOnePaid（→D5 建会话 OneOnOneConversationCreated）；Accepted；LawyerTimeout（→F2 全退）；Finished；Settled（→F3 结算、F2 退差）；DiffPending（15min 未付→按比例结算+G1）。
- 消费：RTC 时长回调（语音视频计量）；ScheduleJobFired（接单超时/实结默认确认/补差 15min）。

## 7. 业务规则
- R-01 计费单位：文字按轮次（50-300/轮）；语音视频按 15min（100-500/15min）｜PRD §9.3
- R-02 预付全额，实结多退少补；补差需用户确认支付（不无密扣款），15min 未付按已服务比例结算+信用 ｜PRD §9.3、架构 §4.1
- R-03 取消三档（精确公式，消除 PRD §9.3 歧义，口径已列入 04§8-16）：
  ① 服务开始前（IN_SERVICE 前）：全额退；
  ② 开始后文字模式：按已完成轮次实结（settle = 单价×已完成轮次），退 prepaid - settle；
  ③ 开始后音视频模式：consumed_units=0（未满首个 15min）收 1 单位 50% 单价、退其余；consumed_units ≥1 按实结多退少补；
  ④ 律师接单超时（paid_at+N 未接单）自动全额退 ｜PRD §9.3、架构 §4.1
- R-04 实结 = 单价 × consumed_units（15min 向上取整）｜PRD §9.3
- R-05 录制按 D5 前置同意执行（1对1 音视频）｜PRD §11.2

## 8. 非功能要求
- 计量回调幂等（重复回调不重复计数）；结算金额争议挂 H3 工单。

## 9. AI 开发标准（本模块附加）
- 交叉审查强制（退补资损）；
- TDD（lj-test-matrix）：三档取消、超时边界、15min 向上取整（1s/15m/15m1s）、补差未付路径、双方确认与默认确认一致性；
- 禁止：补差无确认扣款；计量用 float。
