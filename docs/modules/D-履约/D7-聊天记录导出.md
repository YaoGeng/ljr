# D7 聊天记录导出

> 域：D-履约 ｜ 架构模块：fulfillment + 文件服务 ｜ V1 ｜ P1 ｜ 阶段：④
> 上游：D5（消息）、A4（注销后期权） ｜ 下游：I3（加密包存储）、H9（导出审计） ｜ 技能：P0六件套 + lj-data-security

## 1. 职责与边界
- 做：用户导出自己参与房间的聊天记录——分级导出（本人全量+他人去标识）、异步生成加密包、限时链接、审计；录音本人单独申请通道。
- 不做：文件存储（I3）；权限判定之外的合规解释（H9）。

## 2. 功能点
- 申请（房间维度）；异步任务（生成加密 zip：密码=一次性随机，经 I1 单独下发）
- 分级：本人消息全量；他人消息昵称/ID 掩码、正文保留（证据上下文）、包内附告知文件
- 限时下载（30min 链接过期）；录音调取单独申请（H9 审批）

## 3. 领域模型
export_tasks(id PK, user_id, conversation_id, status varchar(12),  -- PENDING|DONE|EXPIRED|FAILED
  file_ref text, password_hint, expires_at, requested_at, audit_id)

## 4. 关键流程
申请 → 校验参与人 → 异步生成（I3 临时区+加密）→ 通知下载（I1）→ 过期清理。

## 5. 接口契约
| POST | /export/room/{conversation_id} | - | {task_id} | 403 NOT_PARTY / 429 TOO_MANY | 幂等键=user+conv+24h
| GET  | /export/{task_id}/download | - | 302 限时 URL | 410 EXPIRED | 否
| POST | /export/recording/{order_id} | - | {审批工单} | - | 幂等键=user+order

## 6. 领域事件
- 生产：ExportRequested/Completed（→H9 审计、I1 通知）。
- 消费：无。

## 7. 业务规则
- R-01 分级导出：他人去标识（昵称/ID 掩码）正文保留+告知 ｜架构 §5.2 合规 R10
- R-02 录音不在默认范围（单独申请+审批）｜架构 §5.2
- R-03 导出请求入审计 ｜架构 §5.2
- R-04 链接限时失效；密码与链接分通道下发 ｜本设计（安全默认）

## 8. 非功能要求
- 生成异步（大房间 ≤5min）；单人每日导出配额（防爬库）。

## 9. AI 开发标准（本模块附加）
- TDD：非参与人 403、去标识正确性（昵称/ID 正则掩码）、链接过期、配额；
- 禁止：导出包含录音/实名（默认范围外）；明文包落公共存储。

## 10. 验收清单
- [ ] 非参与人被 403
- [ ] 他人消息掩码而正文保留、包内含告知
- [ ] 链接 30min 过期、密码独立通道
- [ ] 导出行为在 H9 审计可查
