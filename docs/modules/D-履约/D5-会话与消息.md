# D5 会话与消息

> 域：D-履约 ｜ 架构模块：RTC/IM 服务 + fulfillment ｜ V1 ｜ P0 ｜ 阶段：②
> 上游：D1（房间）、D6（1对1 会话创建）、A2（撤回事件） ｜ 下游：E1（消息消费）、H5（同步风控）、I3（冷存）、D3（presence） ｜ 技能：P0六件套 + lj-data-security + lj-compliance-guards

## 1. 职责与边界
- 做：conversations 统一会话模型（room/private/one_on_one）；消息发送链路（同步风控→广播→MQ 落库）；per-room seq 读路径；@Agent/@律师差异化；录制前置信令；房间须知展示；训练语料 source_msg_id 标记与撤回删除执行。
- 不做：风控词库与判定（H5）；草稿生成（E1）；文件存储（I3）。

## 2. 功能点
- WSS：join/leave/send/pull(seq)；断线增量拉取；迟到回填（最近 N=200 条）
- 消息类型：text（含 @ 提及）；系统消息（须知/提醒/存证告知）
- @Agent：进 E1 管线 + 非法律意见自动响应（流程指引/信息收集）；@律师：律师端待办高亮
- 录制前置：1对1 双方 recording_consent 信令齐才启动云录制；拼单房间默认不录制
- 房间须知：进房拉取 H7 内容块（含用户侧披露）
- 撤回删除：TrainingConsentRevoked → 按 source_msg_id 反查物理删除语料标记（与 I3 协作）

## 3. 领域模型
conversations(id PK, type varchar(12) NOT NULL,  -- room|private|one_on_one
  ref_id bigint NOT NULL, created_at, UNIQUE(type, ref_id))
messages(
  id bigserial PK, conversation_id bigint NOT NULL, seq bigint NOT NULL,   -- 会话内单调（Redis INCR 发号）
  sender_id bigint NOT NULL, sender_role varchar(12) NOT NULL,            -- user|lawyer|agent|system
  type varchar(12) NOT NULL, content text NOT NULL, mention varchar(12) NULL,  -- agent|lawyer
  risk_flag varchar(12) NULL,                 -- PASS|BLOCKED|REVIEW
  source_msg_id char(36) NULL,                -- 训练语料溯源标记
  created_at timestamptz, UNIQUE(conversation_id, seq)
)
CREATE INDEX ix_messages_conv_time ON messages(conversation_id, created_at);  -- 冷迁移扫描（90 天转 I3）
consent_records(id, ref_type, ref_id, party_id, version, granted_at)      -- 录制与房间级训练授权：ref_type IN ('recording','training_room')

## 4. 发送链路（顺序铁律）
client → WSS send → H5 同步风控（词库双判，≤50ms）→ BLOCKED 即拒（不广播）→ 广播房间成员 → MQ（落库+presence+下游消费）。
MQ 消费用途：持久化、I3 冷存、E1 草稿消费、H5 二次模型复核（命中补拦截+工单）。

## 5. 接口契约
| WSS | join/leave/{conversation_id} | - | presence 事件（MQ） | - | -
| WSS | send | {type, content, mention?} | 200 或 403 BLOCKED_BY_RISK | - | 客户端幂等(msg_client_id)
| GET  | /conversations/{id}/messages?after_seq=&limit= | - | [{seq, sender, content...}] | - | 否
| WSS  | recording-consent | {conversation_id, accept} | 双方齐→启动云录制 | - | 幂等
| GET  | /rooms/{id}/notice | - | 须知内容块（H7 数据） | - | 否

## 6. 领域事件
- 生产：PresenceJoined/PresenceLeft（→D3）；MessageSent{conv_id, seq, risk_flag}（→E1/H5/I3）；OneOnOneConversationCreated（D6 触发）；RecordingConsentGiven；TrainingDataPurged（执行回执→A2/H9）。
- 消费：TrainingConsentRevoked（A2 → 删除执行）；OneOnOnePaid（D6 → 建 one_on_one 会话）；RulePublished（H7 → 须知内容刷新）。

## 7. 业务规则
- R-00 私聊（private 会话）依赖 ⚠04§8-7 决策（私信通道选择）：当前实现支持 private 会话类型，"自动私信未到者"默认走 I1 站内信，决策后切换
- R-01 所有文本会话（房间/私聊/1对1）同一同步风控链路，违规先拦后播 ｜架构 §3.3-1/§6
- R-02 @Agent 仅非法律意见自动响应；法律实质一律律师名义 ｜PRD §7.1.5/§11.1、架构 §4.6
- R-03 录制前置：1对1 双方同意才启动；拼单房间默认不录制 ｜PRD §11.2、架构 §3.3-1
- R-04 训练语料撤回删除：source_msg_id 反查物理删除（未训练样本）｜架构 §5.2 合规 R3
- R-05 聊天留存 ≥3 年（热存 90 天→I3 冷存）｜架构 §5.2 合规 R2
- R-06 私聊限平台内；敏感词触发风控 ｜PRD §7.2.8

## 8. 非功能要求
- 消息端到端 P95 ≤300ms（含风控）；seq 发号吞吐 ≥1k/s；网关节点故障客户端重连任意节点按 seq 补拉（房间态 Redis+DB 可重建）。

## 9. AI 开发标准（本模块附加）
- TDD：风控拦截顺序（BLOCKED 不广播）、seq 连续无洞、断线补拉、双 consent 门、撤回删除执行；
- 禁止：Agent 消息直接进公屏（隔离铁律）；明文 PII 落 MQ 载荷（脱敏标记）。

## 10. 验收清单
- [ ] 违规消息广播前被拦（H5 联调）
- [ ] 断线重连补拉无丢失无重复（seq 校验）
- [ ] 迟到 15min 用户进房可见历史（回填）
- [ ] 单方 consent 不启动录制
- [ ] 撤回后语料标记删除且 H9 收到回执
