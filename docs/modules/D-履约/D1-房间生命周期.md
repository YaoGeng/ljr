# D1 房间生命周期

> 域：D-履约 ｜ 架构模块：fulfillment + RTC/IM 服务 ｜ V1 ｜ P0 ｜ 阶段：②
> 上游：C1/C4（Session 确认）、I2（开房/宽限/结束 job） ｜ 下游：D3（宽限结束判定）、D5（会话创建）、F2（无人到场退款）、H2（监控） ｜ 技能：P0六件套 + lj-domain-rules

## 1. 职责与边界
- 做：到点开房（准点 job 触发）、宽限 5min 计时（锚定约定开始时刻）、IN_SERVICE、结束关闭；开房失败→平台取消分支。
- 不做：到场判定（D3）；消息（D5）；取消规则（D4 的发起方）。

## 2. 功能点
- 开房：I2 job（scheduled_start 准点）→ RTC 服务建房 → Core room OPEN + grace_end = scheduled_start + 5min（不随 opened_at 漂移）
- 宽限结束 job：grace_end 时刻 → 通知 D3 判定
- 无人到场分支：宽限结束全员缺席（含律师）→ 自动关闭 → 平台取消路径（D4 接管，全额退款无信用影响）
- 房间形式（text/voice/video）按场次 room_mode 透传 RTC

## 3. 领域模型
rooms(
  id bigserial PK, session_id bigint UNIQUE NOT NULL,
  mode varchar(8) NOT NULL,                    -- text|voice|video
  scheduled_start timestamptz NOT NULL, opened_at timestamptz NULL,
  grace_end timestamptz NOT NULL,              -- = scheduled_start + 5min（锚定约定时刻）
  closed_at timestamptz NULL, status varchar(16) NOT NULL,  -- OPEN|IN_SERVICE|CLOSED|CANCELLED
  open_fail_reason varchar(64) NULL
)

## 4. 状态机
（job 触发）OPEN（宽限中）→（grace_end + D3 判定有人）IN_SERVICE →（场次时长到/律师结束）CLOSED
OPEN →（全员缺席）CANCELLED(platform) ；开房 job 失败 → CANCELLED(platform, open_fail_reason)。

## 5. 接口契约（内部 job + RTC 回调）
| POST | /rooms/{session_id}/open | job 内部 | {room_id} | 409 ALREADY | 幂等键=session
| POST | /rooms/{session_id}/close | job/律师端 | {closed_at} | 409 NOT_OPEN | 幂等键=session
RTC 回调（建房结果）→ 失败时 RoomOpenFailed 事件。

## 6. 领域事件
- 生产：RoomOpened{room_id, session_id, grace_end}；GracePeriodEnded{room_id}；RoomClosed{...}；RoomOpenFailed{session_id, reason}（→D4 平台取消、F2 全额退款）。
- 消费：SessionFull/Confirmed（预建房间占位）；I2 job 触发。

## 7. 业务规则
- R-01 到点开房；宽限期 5 分钟，锚定约定开始时刻（开房延迟不吞宽限）｜PRD §8.4、架构 §4.5
- R-02 宽限期内无人到场 → 自动关闭 → 自动退款（平台取消路径，无信用影响——限用户侧；全员缺席场次的律师缺席腿仍按 PRD §8.6 联动：信用 -50 + 场次总价 50% 赔付，M2-W4 T2 D-1 回写）｜PRD §8.4/§8.6、架构 §4.1
- R-03 开房任务必须准点；延迟 >30s 电话告警（I2/监控）｜架构 §4.5/§7.2
- R-04 房间形式由律师场次设置决定 ｜PRD §7.1.5

## 8. 非功能要求
- 开房 job 准点率 ≥99.9%；开房动作 P95 ≤2s（含 RTC API）。

## 9. AI 开发标准（本模块附加）
- TDD：宽限锚点（开房延迟 90s 场景 grace_end 不变）、无人到场分支、开房失败分支；
- 禁止：grace_end 用 opened_at 计算；跳过 D3 直接判缺席。
