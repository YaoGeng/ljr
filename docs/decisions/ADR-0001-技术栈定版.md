# ADR-0001 技术栈定版（后端框架与 App）

> 状态：部分裁决（2026-10-13，项目决策人指示）——后端框架与 App 已定；数据库迁移工具仍待裁决
> 关联：架构 §2.3（选型表）；开发计划 §4.1 M0-1/M0-2/M0-3
> 效力：关闭 M0-1「技术栈定版」框架/App 部分；架构 / 开发计划 / 技能指南已按本决策同步

## 决策

| 项 | 定版 |
|---|---|
| App（用户端 + 律师端，双角色） | **Expo**（React Native，单码双端） |
| Core API | **NestJS**（TypeScript；架构 §2.3 原「NestJS / Spring Boot 二选一按团队栈」收敛为 NestJS） |
| 数据库 | PostgreSQL 15（不变，架构 §2.3） |
| 数据库迁移 | **待裁决**：候选 Flyway/Liquibase（架构 §5.2），随 M0-1 遗留子项定，偏离须回写架构脚注 |
| 测试运行器 | 前端/Node 侧默认 bun test（modules/README 通用验收门口径不变）；NestJS 侧 vitest、不与 jest 混用（沿用 M0-1 原推荐口径，最终由脚手架统一固定） |
| Web 运营后台 | React + Ant Design Pro（不变，本 ADR 不涉及） |

## 背景与理由

- 架构 §2.3 原为 NestJS / Spring Boot 二选一按团队栈、App RN/Flutter 待定；开发计划 §4.1 M0-1 要求定版并将决策记录入本目录。
- NestJS + TypeScript：与 App（RN）、后台（React）同为 TS，`shared` 包集中定义类型与领域事件契约；NestJS 模块体系与模块化单体「13 模块=13 schema+DB role」的边界自组织匹配，守卫/拦截器/集成测试工具链成熟。
- rtc-im / agent-assist / payment-gateway 三独立服务实现栈随各自施工定（架构 §2.1 独立伸缩/发布节奏理由不变），Core API 定 NestJS 不改变其独立部署边界。

## 影响与偏离
