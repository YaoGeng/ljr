## 1. 产品概述

### 1.1 问题

个人法律需求高频、碎片、长尾，但传统律师服务贵、门槛高、响应慢；纯 AI 法律助手便宜但深度和可信度不足。供需两端同时存在效率问题：

| 角色 | 问题 |
|---|---|
| 用户 | 律师咨询贵、不知道找谁、小问题不值得花高价 |
| 律师 | 获客成本高、时间利用率低、免费咨询消耗严重 |

### 1.2 产品定位

**AI 增强型法律服务交易平台 = 组团解决法律问题的平台**：通过 AI 降低律师服务成本，通过拼单降低用户咨询门槛，通过深度服务实现商业转化。

**定位口径（2026-10-17 决策人拍板）：**

- **专项（案件类型）是垂直方向，不是平台边界**：劳动仲裁为首发垂直——它是跑通"组团 → 履约 → 付费"机制的验证场；民间借贷（V2）、婚姻家事、经济纠纷等垂直依次复制，平台机制（拼单/履约/信用/分账）全部复用。
- **组团是核心产品机制**：拼团成立的条件 = 同类问题 × 同城 × 同时段；拼单摊的不只是价格，还有信息成本、心理压力与行动风险（用户心态：要上一起上，没人带头都不上）。
- **区域化口径**：城市 = 运营与复制的最小单元；复制双轮 = 垂直 × 城市。**V1 建立城市维度框架**（执业城市字段、场次/拼团城市、同城筛选、用户端城市选择器），首发北京单城运营——多城启动 = 开通供给与运营，不加结构（2026-10-17 决策人指示提前，`docs/08` D-BP8 更新）。
- 商业化后续业务方向（深度服务、双边 VIP、B 端小微企业律师团、职业代理人——并列候选，无主次）见 `docs/08-商业计划书BP.md` §7，本 PRD 只承载 V1/V2 产品规则。

**核心公式：**

```
AI 提升律师效率 + 拼单降低用户价格 + 1对1 提升商业价值 = 新型法律服务基础设施
```

### 1.3 产品飞轮

**用户侧飞轮：**
```
用户增长 → 咨询数据增长 → Agent 增强 → 律师效率提高 → 价格降低 → 用户增长
```

**律师侧飞轮：**
```
律师入驻 → AI 工作台降低负担 → 单位时间收入提高 → 更多律师入驻 → 供给充足 → 用户增长
```

两个飞轮互相咬合：用户侧带来数据，律师侧带来供给，数据增强 AI，AI 同时服务两侧。

### 1.4 战略原则

```
拼单是入口，不是终点。
AI 是增强，不是替代。
律师是节点，不是供应商。
数据是资产，不是副产品。
```

### 1.5 目标

| 阶段 | 验证目标 |
|---|---|
| V1（MVP） | 用户是否愿意低价购买律师时间 |
| V2 | AI 是否显著提高律师效率 |
| V3 | 是否形成法律服务生态 |

### 1.6 非目标

- 全法域覆盖（V1 仅劳动仲裁，V2 增加民间借贷）
- 案件代理撮合（V3 探索方向，需独立合规方案）
- 半熟人邀请制
- 候补补位
- 拼单房间强制视频


## 2. 三层架构

### 2.1 第一层：用户入口层（AI 问题入口）

**目标：** 降低法律服务使用门槛。

**用户心智转变：** 不是“我要找律师”，而是“我遇到了什么问题”。

**示例流程：**

```
用户输入：公司拖欠工资三个月，不给劳动合同，怎么办？

Agent 自动分析：
领域：劳动仲裁
风险等级：中
建议：咨询律师
推荐：今晚 8 点劳动仲裁拼单，99 元
```

**关键能力：**
- 对话式问题收集
- 问题分类到专项
- 风险等级初判
- 推荐匹配场次
- 从对话到报名的转化路径

**版本规划：** V1 保留“浏览场次列表 → 报名”入口；V2 新增对话式 AI 问题入口。

### 2.2 第二层：共享律师服务层（专项拼单咨询）

**核心产品：** 专项拼单咨询。

**特点：** 一个律师、多个用户、固定时间、固定主题。

**示例：**

```
劳动仲裁工资拖欠专题
律师：张律师
时间：周三 20:00
人数：5 人
价格：99/人
剩余：2 席
```

**版本规划：** V1 核心实现，即律师开团 + 用户拼团。

### 2.3 第三层：深度服务层（1对1 与深度服务）

**用户需求升级路径：**

```
普通咨询 → 个人案件分析 → 材料审核 → 策略制定 → 深度服务
```

**对应产品：**

```
拼单咨询 → 1对1 → 深度服务转化
```

**深度服务转化包括：** 1对1 深度咨询、文书代写、合同审查、策略方案定制。均为平台内可闭环服务，不涉及案件代理的合规问题。

**版本规划：** V1 实现 1对1；V2 扩展深度服务转化。（2026-10-22 注：深度服务转化的**货架化形态=非诉小单**已提前至 V1.5 产品扩展批落地，§6.8/§8.11；本层 V2 保留其非货架形态扩展）

| 价格快照 | 用户支付时锁定的价格，后续改价不影响 |

| 1对1价格 | 律师预设的一对一服务价格 |

| 缺席 | 到约定时间未进入房间，超过宽限期 |
| 默认价格 | 律师个人设置中预设的人头价/场次总价/开团人数/接受拼团范围 |
| 开团配置 | 律师创建场次时可修改本次开团的价格与人数 |

| 服务单（2026-10-22） | 用户购买非诉小单后形成的订单：支付 → 律师接单 → 交付 → 确认 → 结算 |


## 6. 整体业务流程

### 6.1 律师配置（App 律师端）

**时间表：**
- 设置可预约时间段（支持按周重复）
- 设置单场时长（60/90/120 分钟）
- 时间表标记每个时间段状态：空闲 / 已占用 / 已锁定
- 已排期场次不受时间表变更影响

**默认价格配置（个人设置）：**
- 人头价：每人单价——默认值
- 场次总价：整场总价——默认值
- 开团固定人数——默认值
- 接受拼团人数范围（下限 + 上限）——默认值
- 房间沟通形式：文本 / 语音 / 视频（可多选）
- 1对1服务价格（按服务类型 × 沟通形式预设）
- 修改默认价格时记录版本号，通知已参与拼团用户

**定价逻辑：**
- 人头价：用户支付固定单价，律师收入 = 单价 × 实际成团人数
- 场次总价：用户按“总价 ÷ 选定最低人数”支付固定分摊额，律师收入 = 分摊额 × 实际成团人数

### 6.2 律师开团（B2C）

```
律师从时间表选时间段 → 进入开团配置页
→ 系统自动填入默认价格和默认开团人数
→ 律师可修改本次开团的价格与人数（仅本次有效）
→ 创建场次（锁定时间段）
→ 用户浏览场次 → 报名支付 → 满员成团 → 锁人
→ 多轮提醒 → 到点开房 → 宽限期 → Agent+律师服务
→ 缺席处理 → 房间结束 → 结算 → 申请1对1 → 评价
```

**规则：**
- 人数由律师选定，固定不变
- 满员即成团，成团后不再接受新报名
- 未满员到成团截止时间 → 流标 → 全额退款
- 开团时修改的价格和人数仅对该场次有效，不改变默认值

### 6.3 用户发起拼团（C2B）

```
用户选专项 → 选律师 → 从时间表选时间段（锁定）
→ 查看律师默认的接受拼团人数范围
→ 从范围内选子范围（如 5-6 人）
→ 系统按默认场次总价 ÷ 子范围最低人数，算每人分摊额
→ 填写结构化问题标签 → 发布拼团（锁定价格快照）
→ 其他用户加入（按快照价格支付）
→ 达到子范围最低人数 → 成团 → 锁人 → 待律师确认
→ 律师确认 → 进入房间履约流程
```

**规则：**
- 子范围必须在律师默认的接受拼团人数范围内
- 价格按律师默认场次总价计算，用户支付固定金额
- 成团后人数锁定，不补不退
- 律师收入 = 分摊额 × 实际成团人数
- 用户拼团使用默认场次总价和接受范围，不受某次开团修改影响
- 子范围人数不可修改，只能取消后重新发起

### 6.4 双向协同

- 律师可将高需求 C2B 任务“认领”并转化为 B2C 场次
- 原任务转“已转化”，已参与用户自动迁移，维持快照价
- 新加入用户按 B2C 定价
- 通知已参与用户，24h 内可申请退款

### 6.5 时间段占用锁

- C2B 发起 / B2C 创建时，立即锁定该律师该时间段
- 同一律师同一时间段只能存在一个有效场次
- 锁释放：流标、律师拒绝/超时、用户取消、场次取消
- 时间表标记“已占用”不可选

### 6.6 快速1对1解答（2026-10-22 增补）

**定位**：即时、轻量的付费咨询——「小问题不值得等一场拼团」的入口产品；也是律师响应速度与专业度的展示面。

```
用户发起咨询单（问题标签引导 + 期望时长 ≤30min + 联系方式明示/隐藏开关）
→ 律师在抢单大厅查看（看不到任何报价金额——价格不公布）→ 提交报价
→ 用户从收到的报价中选定一位律师 → 按报价支付（价格快照）
→ 生成 ≤30 分钟 1对1 会话（沟通形式按律师设置）→ 到时自动结束
→ 双边评分（用户评律师 + 律师评用户）
```

**规则要点**（完整规则 §8.9）：
- 时长上限 30 分钟，锚定会话开始时刻；会话复用 1对1 通道（文本/语音，按律师设置）
- **律师价格不公布**：报价仅发单用户与报价律师本人可见；列表、大厅、订单详情（对第三方）均不展示报价
- **双边评分**：双向互评，评价入双方信用（用户端影响拼单信用，律师端影响排序因子）
- **联系方式可选**：用户可明示联系方式（对可报价的审核通过律师可见）或隐藏（仅平台内会话沟通）；平台外收款引导照常风控拦截
- 律师同一咨询单仅一个报价，报价截止前可撤回重报；发单超时无报价或未选定则自动关闭（未支付零资金占用）

### 6.7 批量诉讼拼团（同司团，2026-10-22 增补）

**定位**：组团机制的垂直深化——劳动仲裁天然「同公司批量」：同一用人单位下多名劳动者遇同类问题，组团=共用一名律师、分摊成本、口径一致。

```
发起人选「批量诉讼拼团」模式 → 选案件类型（垂直）+ 填用人单位（对方公司名）
→ 选律师 + 锁时间段 + 子范围（与标准 C2B 一致）→ 发布（快照价）
→ 其他用户加入：须声明同一用人单位（规范化匹配校验），按快照价支付
→ 达最低人数成团锁人 → 律师 12h 内确认（复用 C2B 确认流）→ 履约
```

**规则要点**（完整规则 §8.10）：
- 成团三前提升级：同类问题 × 同城 × **同用人单位**（批量团专属第四锚）
- 用人单位名称规范化匹配（去首尾空格、全半角括号统一）；律师履约前核验劳动关系材料，发现不同公司按取消规则处理
- 虚假加入（非同司）→ 信用扣分；团队成员昵称脱敏展示
- 律师收入 = 分摊额 × 实际成团人数（与标准 C2B 一致）

### 6.8 律师非诉小单货架（2026-10-22 增补）

**定位**：律师把非诉服务「商品化」——固定内容、固定价格、即买即约；用户可浏览律师列表/找律师后直接购买，不需要等拼团。是深度服务转化（§2.3/§9.4）的货架化落地。

```
律师配置非诉小单（套餐名 + 内容清单 + 价格 + 交付方式，自主定价，可上下架）
→ 用户在找律师/律师主页浏览货架 → 选套餐 → 支付（价格快照）
→ 生成服务单 → 律师接单 → 平台内会话交付（可附文件）→ 用户确认完成
→ 结算（律所对公）→ 双边评价
```

**套餐形态示例（律师自主定价，以下仅为示意，非平台指导价）**：
- 阶梯套餐：单独咨询 ¥300/次；咨询+诉讼文书 ¥500；咨询+诉讼文书+立案指导 ¥1500
- 全程套餐：案件全程陪跑（咨询、文书、证据收集指导、指导立案、程序指导、庭前培训）¥2500

**规则要点**（完整规则 §8.11）：律师接单前全额可退；接单后未开始交付申请取消走协商/工单；律师超时未接单自动退款；交付与确认全平台内闭环，不涉出庭代理（§14 合规边界不变）。

## 8. 拼单与履约规则

### 8.1 成团规则
- 律师开团：报名满律师选定人数 → 成团 → 锁人
- 用户拼团：加入满子范围最低人数 → 成团 → 锁人 → 待律师确认
- 成团后均不接受新报名
- 未达选定人数到截止时间 → 流标 → 全额退款

### 8.2 价格快照与改价规则

**核心原则：** 用户支付时价格即为最终价格。已锁定价格的用户不受律师后续改价影响。

**改价窗口：**

| 律师状态 | 能否改价 |
|---|---|
| 无进行中拼团 | 自由改价 |
| 有进行中拼团 | 受限，见下表 |

**有进行中拼团时的改价规则：**

| 改价方向 | 是否允许 | 对已锁定用户 | 对新发起拼团 | 律师惩罚 |
|---|---|---|---|---|
| 涨价 | 允许 | 按快照价 | 按新价 | 信用 -5 |
| 降价 ≤10% | 需平台审批 | 按快照价 + 平台积分补偿 | 按新价 | 信用 -15 |
| 降价 >10% | 需平台审批 | 按快照价 + 积分补偿 + 优惠券 | 按新价 | 信用 -30，暂停接单 3 天 |

**补偿规则：**
- 补偿对象：所有已支付且未完成服务的用户
- 补偿形式：平台积分（1 元 = 100 积分，有效期 180 天，可用于拼单抵扣，不可提现）
- **积分抵扣比例：100 积分 = 1 元，单次抵扣不超过订单金额 50%**
- 补偿金额 =（原价 - 新价）× 用户已支付金额占比
- 发放时间：降价生效后 24h 内

**改价撤销：**
- 改价后 24h 内可撤销，恢复原价
- 撤销不扣信用，需通知已受影响用户
- 超过 24h 不可撤销

**改价频率限制：**
- 每 30 天最多改价 3 次（含涨价与降价）
- 超过频率限制需平台审批
- 恶意频繁改价 → 信用 -20，严重者暂停接单

**改价记录：** 所有改价记录进入 `PricingHistory` 表。

**改价通知话术：**

涨价时（已锁定用户）：
> “您已锁定原价，当前律师已调价，您享受的是涨价前的价格，不受影响。”

降价时（已锁定用户）：
> “您参与的服务价格有所调整，您已锁定的原价不受影响。为感谢您的信任，我们已为您申请平台积分补偿，将在 24 小时内到账。”

降价 >10% 时（已锁定用户）：
> “您参与的服务价格大幅调整。您已锁定的原价不受影响，我们已为您申请积分补偿 + 额外平台优惠券，将在 24 小时内到账。感谢您的信任与支持。”

### 8.3 提醒机制
- 开始前 24h / 1h / 10min / 1min 自动推送
- 房间内 Agent 同步提醒
- 用户可“确认到场”或“申请改期”

### 8.4 到场与宽限
- 到点开房，宽限期 5 分钟
- 宽限期内 Agent 暖场、收集问题
- 系统自动私信未到者
- 宽限期内无人到场 → 自动关闭 → 自动退款

### 8.5 用户缺席处理

| 情形 | 处理 |
|---|---|
| 宽限期内进入 | 正常参与 |
| 超宽限 ≤15min 进入 | 可旁听，不退费，不重新计时 |
| 超 15min | 视为缺席，费用不退 |
| 缺席费用去向 | 70% 归律师 + 30% 以平台积分发到场用户 |
| **30% 积分分配规则** | **按到场用户支付金额占比分配** |
| 信用 | 扣分，多次限制拼单 |

### 8.6 律师取消/缺席规则

| 情形 | 处理 |
|---|---|
| 律师取消 ≥24h | 可取消，全额退款用户，信用 -10 |
| 律师取消 <24h | 需平台审批，全额退款 + 信用 -30 + 场次总价 20% 违约金补偿用户 |
| 律师缺席（宽限期未进场） | 自动终止 + 全额退款 + 信用 -50 + 场次总价 50% 赔付 |
| 连续 2 次取消/缺席 | 暂停接单 7 天 |

**场次总价基数：**
- 人头价模式：场次总价 = 单价 × 律师选定人数
- 场次总价模式：场次总价 = 律师设定的场次总价（开团时修改的以修改后为准）

**违约金分配：**
- 律师取消 <24h 的 20% 违约金，全额补偿用户，平台不抽佣
- 按用户支付金额占比分配

### 8.7 取消规则

| 角色 | 时间 | 处理 |
|---|---|---|
| 用户 | 开始前 ≥2h | 全额退或免费改期一次 |
| 用户 | 开始前 <2h | 退 50% 或扣信用 |

## 9. 费用与结算

### 9.1 计价方式

**人头价**
- 律师设定每人单价（默认值，开团时可修改本次价格）
- 用户按固定单价支付
- 律师收入 = 单价 × 实际成团人数

**场次总价**
- 律师设定场次总价（默认值，用户拼团使用此默认值计算分摊额；律师开团时可修改本次总价）
- 用户拼团按“默认总价 ÷ 选定最低人数”支付固定分摊额
- 律师开团按“本次开团修改后的总价 ÷ 本次开团人数”计算单价
- 律师收入 = 分摊额 × 实际成团人数

**共同规则：**
- 成团即锁人，不补不退
- 用户支付时看到多少就付多少
- 律师收入随实际成团人数浮动

### 9.2 用户发起拼团费用
- 用户选择律师时看到律师默认的接受拼团人数范围
- 用户选子范围，系统按默认场次总价 ÷ 子范围最低人数算分摊额
- 发起时锁定价格快照
- 其他用户加入按快照价支付
- 律师改价不影响已发起拼团
- 子范围人数不可修改，只能取消后重新发起

### 9.3 1对1费用

| 形式 | 计费单位 | 律师定价区间 | 结算 |
|---|---|---|---|
| 文字 | 按“次”（1 轮深度问答） | 50-300 元 | 预付全额，实结多退少补 |
| 语音/视频 | 按 15 分钟 | 100-500 元 | 预付全额，实结多退少补 |

**取消规则：**
- 服务开始前可全额退
- 服务开始后按比例退（未满 15 分钟按 50%）
- 律师超时未响应 → 自动退款

### 9.4 深度服务转化费用（V2）
- 文书代写、合同审查、策略方案定制
- 律师预设价格，平台内闭环
- 具体规则 V2 阶段定义
- **2026-10-22 注**：其货架化形态（非诉小单：固定内容+固定价格+即买即约）已提前至 V1.5 产品扩展批落地——计价与结算见 §6.8/§8.11/§9.6；本节保留 V2 非货架形态（议价类深度服务）

### 9.5 结算与合规
- 用户支付 → 持牌支付机构分账（微信电商收付通 / 支付宝直联分账）
- 资金不过平台账户
- 服务完成 → 直接结算至律所对公账户 + 平台服务费
- **平台服务费：前期 0%，V1 跑通后逐步抽 5%-10%**
- 1对1 同样走持牌机构分账
- 禁止使用平台自有银行账户做资金中转

### 9.6 扩展业务费用（2026-10-22 增补）

**快速1对1解答**
- 计价：律师竞价——用户从报价中选定，按报价金额预付全额（价格快照）
- 结算：服务完成按实结（≤30 分钟一价全包，不另计量计费——与 §9.3 预设计价的「多退少补」不同，快速单一价包干）；取消/超时退款按 §8.9
- 走持牌机构分账，资金口径同 §9.5

**非诉小单**
- 计价：按服务商品固定价预付全额（快照）
- 结算：用户确认完成/超时自动确认 → HOLD → 律所对公（§9.5）；取消退款按 §8.11
- 平台服务费：试运行期免收口径不变（04 §8 #40）；公开上线后并入统一抽佣节奏，无独立费率


## 10. 核心壁垒

### 10.1 壁垒一：法律专项 Agent

不是通用 AI，而是劳动仲裁 Agent、婚姻家事 Agent、债务纠纷 Agent、合同纠纷 Agent。每个专项拥有法律知识库、问题树、风险判断、律师辅助模板。

**V1 状态：** 劳动仲裁 Agent 已规划，Agent 草稿气泡已实现。

### 10.2 壁垒二：律师 AI 工作台

未来律师进入平台不是为了“接订单”，而是为了“提高生产力”。

**V1 能力：** 回复草稿生成 + 律师审查发送。
**V2 扩展：** AI 总结、事实提取、法律风险分析。

### 10.3 壁垒三：法律服务数据资产

**每一次咨询产生：**

```
用户问题 → 事实结构 → 律师回答 → 用户反馈 → 最终结果
```

**数据资产类型：**

| 数据类型 | 用途 | 合规要求 |
|---|---|---|
| 脱敏后的房间问答记录 | Agent 训练 | 用户隐私脱敏 |
| 事实结构提取 | 问题树优化 | 去除可识别信息 |
| 律师回答模板 | 草稿质量提升 | 律师知识产权归属 |
| 用户反馈 | 质量评估 | 数据使用授权 |
| 最终结果追踪 | 效果验证 | 匿名化处理 |

**合规边界：**
- 用户隐私脱敏后方可用于训练
- 律师知识产权归属需在入驻协议中明确
- 数据使用授权需在用户协议中前置说明
- **房间消息留存期限：服务结束后保留 2 年，用户可导出自己的聊天记录**


## 11. 关键设计决策

### 11.1 语音/视频房间中 Agent 草稿呈现

- Agent 输出永远不直接进入房间公屏
- 纯语音模式下，草稿以耳机内语音提示仅律师可听

### 11.2 1对1视频/语音录音录像留存
- 服务开始前弹窗告知，双方确认
- 云端录制，原始文件存合规存证平台（带区块链哈希）
- 关联 1对1订单，仅合规审核人员可调取
- 留存期限不少于 2 年

### 11.3 首发城市与律师供给

- 首发城市：北京
- **分层供给策略（2026-10-16 决策人确认）**：
  - **冷启动主力 = 时间充裕型律师**：质量底线为执业 ≥3 年 + 劳动法代理经验；案源饥渴 + 时间富余的动机结构决定履约质量——接单率/到场率优先于名气，越闲越好
  - **信任锚 = 1-2 名有头衔/有粉丝的律师**：为平台背书，量不在多
  - **内容型律师（原「1 万粉」标准）后置至增长期 BD**：其价值在获客侧（短视频带流量）而非履约侧
- **找律师合规管线**：官方公开名录筛人（司法局/律协执业公示、12348 律师库、裁判文书劳动法代理记录——执业年限×专长可结构化筛选）→ LLM 清洗/分级/生成个性化触达文案 → 人工邮件/电话触达；小红书/抖音仅作「是否在做内容」的加分项核查。**红线：不做平台数据批量采集、不做自动化群发；自有账号人工合理推广（笔记为主、评论区为辅）**
- 招募条件：前期不抽佣 + 平台流量扶持
- 内容策略：律师短视频获客 → App 转化闭环（配合内容型律师在增长期引入）

- 审核字段：发送者、会话类型、审核结果
- AgentReviewLog 记录：草稿内容、律师修改、动作（直接发送/修改后发送/丢弃）、审查耗时
- 核心分析指标：直接发送率、修改率、丢弃率

### 11.5 供给端冷启动

| 律师痛点 | 律聚人方案 |
|---|---|
| 获客成本高 | 平台流量扶持 + 短视频获客闭环 |

### 11.6 公域获客管线（需求侧冷启动，2026-10-17 增补）

- **信号源**：小红书/抖音等平台存在大量劳动争议一手自述（克扣/拖欠工资、变相裁员调岗逼自离、"正在准备仲裁"等），评论区大量律师公开邀约咨询——供需两端已在公域聚集，平台做接线。

- **供给侧联动**：公域内容活跃度作为律师招募的加分项核查与优先级信号（§11.3）。
- **城市颗粒度**：采样、投放、社群渗透均按城市运营——同城是拼团成立的地理前提（成团条件=同类问题 × 同城 × 同时段）。

## 14. 非目标与合规边界

### 14.1 V1 非目标
- 全法域覆盖（V1 仅劳动仲裁）
- 案件代理撮合（V3 探索方向，需独立合规方案）
- 半熟人邀请制
- 候补补位
- 拼单房间强制视频

### 14.2 合规边界
- 律师费必须入律所对公账户，平台收技术服务费
- 资金通道：持牌支付机构分账，资金不过平台账户
- 禁止平台外交易、私下转账、个人收款
- 私聊内容留存，敏感词风控
- Agent 回复标注辅助性质，不构成法律意见
- 缺席扣费规则显著提示，写入用户协议
- 用户隐私：房间内容脱敏后方可用于训练
- 律师执业合规：不得承诺结果、不得虚假宣传
- 律师主页实力档案：信息须真实，资质类字段经审核核验；虚假填写 → 下架档案/信用扣分/清退
- 1对1视频/语音需符合平台录音录像留存要求
- 案件代理不纳入平台撮合，仅作为 V3 探索方向
- **快速单联系方式边界（2026-10-22）**：明示联系方式仅对平台审核通过的律师可见，非公开信息；禁止借快速单引导平台外收款/交易（风控词库覆盖快速单描述与会话）；「价格不公布」同时约束平台侧展示与通知文案
- **非诉小单合规边界（2026-10-22）**：服务商品内容不涉出庭代理（案件代理撮合仍为 V3 探索、独立合规方案前置）；套餐描述禁「包赢/保证结果」话术；「全程陪跑」定位=指导与陪同服务，非诉讼代理
