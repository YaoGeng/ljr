**全局约束（每任务隐含）：**
- 前端批不动 core/shared/services 契约面；shared 只消费（build 产物先行：`pnpm --filter @ljr/shared build`）
- 金额展示：NUMERIC 字符串→formatMoney 单一出口；状态字段展示经映射表禁散写三元；错误码→文案经 error-messages 单源扩
- 设计铁律：豆沙红 `#C25E5E` 仅极小面积点缀（焦点卡/价格数字/主按钮/危险态），严禁大面积铺色；主色橄榄绿 90% 面积；禁止外链资源
- E1 合规面：占位符还原显示仅律师端草稿卡；草稿正文 R-04 标记不可剥离展示；Agent 输出无律师动作不进会话（UI 层不造发送捷径）
- 密钥/凭据禁入源码；API base URL 走 env（EXPO_PUBLIC_*）；dev 取码/支付模拟凭据沿 W1 夹具纪律
