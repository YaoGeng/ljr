## 2. 关键决策（逐条）

1. **点缀红铁律**：`accent #C25E5E` 仅允许出现在——主按钮（一组仅一个）、价格数字（T2+ 经 `splitMoney` 拆段着色）、激活 tab 位点（4px）、危险/错误态（错误文案+非法描边）。严禁大面积铺色；`Button` 组件 `variant="primary"` 是唯一的红底出口，卡片底色禁用红。
2. **玻璃卡 blur 降级**：RN 无 `backdrop-filter`，且按 W1-3 同款零依赖纪律不引 expo-blur——玻璃卡以 `rgba(255,255,255,.5)` 底 + 1px `glassHi` 白边 + 16px 圆角近似（`GlassCard` 组件）。**登记为 dev 期降级**：真机玻璃质感（背景光晕透出）后续批次若需补齐，再评估 expo-blur（届时走依赖变更决策，非本卡）。
3. **图标策略**：不引 react-native-svg/图标库——`src/components/icons.tsx` 用纯 View 绘制极简几何图标（边框三角/圆/圆角矩形；首页屋顶/日历/圆加号/对话气泡/人形/返回/登出）。正式图标体系（线宽/光学网格规范）后续批次定，本批只保证结构与色彩语义可替换。
4. **字体**：系统无衬线（RN 默认字体栈，web 端落到浏览器系统字体），禁外链字体（全局约束：禁止外链资源）。
5. **间距/圆角标尺**：见 §1 尾段；组件样式一律引用 token，`StyleSheet.create` 内禁止出现未入表的魔法色值（`rgba(255,255,255,.55/.62/.66)` 三档半透明白为顶栏/底栏/输入底的玻璃面变体，随玻璃降级口径走，已注释标注原型对应值）。
6. **导航信息架构**：五 tab（**首页/场次/发团/消息/我的**，`TAB_ROUTES`）+ 推栈（`push/pop` 栈数组，`STACK_ROUTES` 登记 key+标题；本批仅 `sessionDetail` 一个推栈占位，T2 场次详情接管）。tab 切换=pop-to-root（切 tab 即清推栈回该 tab 根，评审修复 I1；状态机为纯函数模块 `navigation-state.ts`，router.tsx 仅做 React 绑定）。注：任务卡五 tab IA 为准（原型用户端为四 tab「首页/我的拼单/消息/我的」，非骨架依据）；发团 tab 为中央主操作位（红主按钮页心）。

## 3. API/契约对接决策（A1 登录）

- 契约实读（identity.controller/service）：`POST /auth/sms {phone}→{ttl}`、`POST /auth/verify {phone,code,age_declared?}→{access_token,refresh_token,roles}`、`GET /me→{id,roles,status,phone_masked}`、`POST /auth/logout {refresh_token}`、`POST /auth/refresh`。错误体全仓统一 `{code,message}`（AppHttpExceptionFilter）。
- 客户端错误映射：`AppApiError{code,httpStatus,serverMessage,message}`；用户文案经 `src/api/error-messages.ts` 映射表（禁散写三元），表外码回退服务端 message 再回退通用文案。客户端本地码 `CLIENT_NETWORK`/`CLIENT_BAD_RESPONSE`/`CLIENT_BAD_REQUEST`（T2 评审 S6 增：本地入参拒绝，请求未发出——与「响应形状非法」分码）属前端层信号，不入 shared 契约表（登记于此）。
- 会话：token 内存态 + `useSyncExternalStore` 订阅；/me 401 单飞 refresh 自愈一次；verify 成功但 /me 失败回匿名态（不滞留半登录态）。持久化后置（W1-5；零依赖红线本批也不装 AsyncStorage）。
- **dev 取码实况（triage，不修 core）**：mock SMS 通道零副作用（notify.channels.ts），验证码随机生成仅哈希落库，响应无 devCode 回显、无固定 dev 码、无日志落码——**dev/E2E 无法经 API 面取得验证码**。可行后置项（供拍板）：a) core dev profile 响应回显 devCode；b) dev 固定码旁路；c) E2E 夹具直插 `identity.verify_codes`（哈希 `sha256(code:blind_idx)` 确定性可行，但需读 pepper 配置）。T5 E2E 前必须先拍板其一，否则登录旅程不可自动化。
