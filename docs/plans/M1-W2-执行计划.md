2. TDD：模块文档 §7 每条 R-xx 至少 1 用例先行（RED→GREEN 证据入报告）；§9 附加用例一并落

**全局约束（每任务隐含）：**
- 只写本模块架构 schema（A 系=identity、B1=schedule、B3=pricing、G1=credit）；跨模块取数走接口或事件，**跨 schema 不建 FK**（W1 惯例，bigint 裸引用）
- 金额一律 NUMERIC+Money 字符串往返禁 float；时间一律 timestamptz（Asia/Shanghai）；状态字段经状态机守卫+state_transition_log 禁裸写
- PII 红线：phone/id_no/license_no 明文禁落库（列加密）、禁落日志、禁进事件载荷（lj-data-security；盲索引/HMAC 密钥经 env 注入，凭据零字面量）
- dev 无 Redis 的等价实现+适配位（W1 共性 R3/R6/R11 延续）；admin 面 REST 鉴权占位（随 H1/H2 W3+）
- 外部供应商一律 mock 适配器：SMS 走 I1 已有 mock 通道、实名走 D12 mock 适配器；出站校验拒绝环回/私网 host
- 复跑前置：PG 5435 存活检查 → `pnpm --filter @ljr/shared build` → 测试（W1 教训 §4-D）
