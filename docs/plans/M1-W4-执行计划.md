**每任务门（docs/05 §2 SOP 继承，集成验收批裁剪）：**
1. 实现前读：本计划对应行+services/core/AGENTS.md+根 AGENTS.md 硬约束+相邻已落位代码（T1 必读：schedule/scheduler-alerts.ts（告警形态）、scheduler.catalog.ts（job 注册）、W3 各域检测相关服务面）
2. TDD：巡检五类检测先红后绿（故障注入用例先行）；§9 附加用例一并落
3. 迁移：V34 全限定 ops schema → `pnpm gen:table-manifest` → 同步 testing/db.ts TEST_DB_TABLES；**注释自查先于 apply**（W3 教训 §4-4，V25 起纪律）
4. 自验：`pnpm -r test`（core vitest 串行连 PG，**安静系统执行**——W3 教训 §4-5：垂死代理进程致 fork 池崩溃，全量跑前确认系统无高负载进程；`pnpm test \| tail` 管道掩蔽 exit code 禁用，改 EXIT_CODE 捕获）+ lint + schema-refs 0
5. 评审：T1 code-reviewer（+ops 域非资金面，无强制交叉审查；检测 SQL 涉资金数据只读面仍按 lj-payment-invariants 装载复核）；T3/T4/T5 对应专业角色（general-purpose 承载，R-W3-D 环境裁决延续——角色纪律内嵌派发简报，显式引用 SKILL 路径）
6. 完成后：控制者台账勾账+任务报告

**全局约束（每任务隐含）：**
- 只写本域架构 schema（巡检执行器+台账=ops；检测函数各域自持）；跨域核对走导出接口应用层聚合，**禁跨 schema join**（check-schema-refs 0 为门）
- 巡检=只读面：不写业务域任何表（findings 台账在 ops）；不修因只报因（W3 triage 开放项如 AttendanceGate 时序缝保持 M2，巡检只做检测）
- 金额 NUMERIC+Money 字符串往返；时间 timestamptz（Asia/Shanghai）；阈值窗口判定锚 DB 钟（A3b R-03 双钟教训）
- 告警=供应商位形态（外部对接后置）：零外部调用、零凭据、零字面量
- 复跑前置：PG 5435 存活检查 → `pnpm --filter @ljr/shared build` → 测试；**代理中断会连杀 portable PG**（memory 教训），中断后先查库再重跑

**Review Focus（本批最可能咬人的五类）：**
1. **巡检自身幂等**——同违例多轮巡检不重复入账（dedup 键未 resolved）；巡检 job 自身 FAILED 不产生误告警噪音（REMIND_*/ROOM_OPEN NO_EXECUTOR→FAILED 已知噪音 04 §8 #33，巡检对 schedule_jobs 违例判定需与该已知形态区分/豁免，避免上线即误报刷屏）
2. **检测窗口假阳/假阴**——>10min 窗口的时钟锚（updated_at vs 终态迁移时刻，锚 STL）；批量退款在途不误报（F2 PROCESSING 中间态=在途不算未发起）；mock 通道「渠道未确认」在 mock 形态下的语义（mock 同步确认无窗——检测面留 M2 真通道换装注记即可，不强造假阴用例）
3. **清零断言真实性**——正常链路零 findings 必须真跑（w3-smoke 夹具复用非新造简化夹具）；防「巡检永远零发现」的空转形态（用故障注入红用例证非空转，mutation 红证据沿 T11 先例）
4. **flaky 收敛不弱化断言**——放宽阈值/重试仅针对时间性构造证型，断言语义不变（sanitize 50ms 上限调整须注记理由，非删除性能冒烟）
5. **盘点口径不漂移**——桩清单盘点以 W3 计划 v1.4 为唯一事实源，现状与清单差异=发现（如批内已闭环项）须回写而非静默
