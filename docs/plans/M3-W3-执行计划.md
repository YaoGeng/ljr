**全局约束（每任务隐含）：**
- 前端批不动 core/shared/services 契约面；shared 只消费（build 产物先行：`pnpm --filter @ljr/shared build`——admin 消费 @ljr/shared 类型/错误码时）
- admin API 面=既有端点零扩面：admin/lawyers 五+tickets 五+risk queue/review+词库 GET/PUT+rules 五+pricing approve/histories+dashboard/metrics（§预检已枚举 16 控制器——admin 面 26 端点在册，W3 页面消费其中 22）
- 状态字段展示经映射表禁散写三元；错误码→文案单源；金额 NUMERIC 字符串→formatMoney 单出口
- 设计铁律：人民币双色系——橄榄绿主色约 90% 面积、豆沙红 `#C25E5E` 仅极小面积点缀（焦点卡/危险态/主按钮），严禁大面积铺色；后台无深色模式；禁止外链资源（CDN/字体/图标库）
- 密钥/凭据禁入源码；API base 走 env（VITE_* 构建期注入）；admin token 仅 localStorage 运行态
- 危险动作（audit reject/suspend/publish/approve false/resolve false）必须确认门；reason 必填面服务端校验+前端防呆双层
