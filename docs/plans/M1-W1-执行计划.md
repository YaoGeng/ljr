**每模块门（docs/05 §2 SOP 全量）：**
1. 实现前读：模块文档全文 + services/core/AGENTS.md + 根 AGENTS.md 硬约束 + 相邻基座代码（modules/demo 形态、infrastructure/*）
2. TDD：模块文档 §7 每条 R-xx 至少 1 用例先行（RED→GREEN 证据入报告）
3. 迁移：V<n> 全限定 schema 名 → `pnpm gen:table-manifest` → **同步 testing/db.ts 的 TEST_DB_TABLES**（core/AGENTS.md WHERE TO LOOK）
4. 事件：§6 领域事件经 recordOutbox 同事务写；消费端幂等
5. 自验：`pnpm -r test`（core vitest 串行连 PG）+ `pnpm lint` + `node scripts/check-schema-refs.mjs` 全绿
6. PR 四件套 + code-reviewer 评审 + 修复环（5 轮上限）
7. 完成后：控制者台账勾账；模块文档 §10 由实现者在 PR 证据中逐项对照

**随首个模块 PR 一并的回写补丁（ADR-0003 评审遗留 Minor）：**

**工作约定（用户 2026-10-14，全模块适用）：**
- 待澄清项按架构默认值/mock 口径实现并标 ⚠ 决策位，集中汇报需拍板项；仅重大/不可逆阻塞
