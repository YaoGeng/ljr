**每任务门（docs/05 §2 SOP 继承）：**
1. 实现前读：本计划对应行+涉及模块文档 §5 契约+prototype 对应视图+根 AGENTS.md 硬约束+apps/app 相邻代码
2. TDD 口径（前端适配）：API client 与状态映射层至少 1 用例/bun test；视图以 E2E+截图自检承载（T5 每旅程至少 1 全贯通用例）
3. 迁移：预期零新迁移零 core 改动；发现 API 缺口（字段缺/端点缺）→ 停卡列 triage，不得自行改 core 契约
4. 自验：`pnpm --filter @ljr/app typecheck` + `expo export --platform web` EXIT=0 + bun test（app 内用例）+ E2E 输出粘贴任务报告
5. 评审：T6 code-reviewer 全量；T1 设计决策说明按 §8.2 截图自检；T5 按 §8.2 运行输出留档
6. 完成后：控制者台账勾账+任务报告（.superpowers/sdd/M3-W1-执行计划/）

**全局约束（每任务隐含）：**
- 前端批不动 core/shared/services 契约面；shared 只消费（build 产物先行：`pnpm --filter @ljr/shared build`）
- 金额展示：NUMERIC 字符串→格式化单一出口（`formatMoney`），禁 parseFloat 裸算；状态字段展示经映射表禁散写三元
- 设计铁律：豆沙红 `#C25E5E` 仅极小面积点缀（焦点卡/价格数字/主按钮/危险态），严禁大面积铺色；主色橄榄绿 `#3E5C3A` 系 90% 面积；禁止外链资源（字体/图标/图片全内嵌或系统字体）
- 支付交互=直接成功口径（#40），不实现收款信息页/凭据登记/通道拉起
- 敏感面：用户原文进 LLM 前脱敏属后端管线（M2 已落），前端不新增 LLM 调用；训练授权=A2 独立页独立勾选
- 密钥/凭据禁入源码；API base URL 走 env（EXPO_PUBLIC_* 或 app config dev 默认 localhost）
