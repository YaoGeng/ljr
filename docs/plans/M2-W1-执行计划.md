- NO_EXECUTOR 消失面：REMIND×4+REMIND_GRACE_END（T4 装配）+ ROOM_OPEN/GRACE_END（T1 装配）+ RETENTION_PURGE/COLD_ARCHIVE（真注册）——04 §8 #33 关闭条件=装配后复跑零该类 FAILED（reminder.spec 零 NO_EXECUTOR 断言+全量复跑双证）。

### A.3 DDL 蓝图（列级对齐模块文档 §3；TDD 用例的列锚以此为准）

- **V35__fulfillment**：`rooms(id bigserial PK, session_id bigint UNIQUE NOT NULL, mode varchar(8) CHECK IN (text,voice,video), scheduled_start timestamptz NOT NULL, opened_at timestamptz NULL, grace_end timestamptz NOT NULL, closed_at timestamptz NULL, status varchar(16) CHECK IN (OPEN,IN_SERVICE,CLOSED,CANCELLED) NOT NULL, open_fail_reason varchar(64) NULL)`——grace_end=scheduled_start+5min 应用层锚定（禁 DB 默认值表达式掩盖锚点语义）；
