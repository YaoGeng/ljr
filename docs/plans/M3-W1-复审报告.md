## 3. 缺口与 triage（04 §8 #48 登记）

**前端对接契约缺口（core 侧，待拍板/另卡，不阻塞 W2）**：①GET /sessions 公开列表硬编码 status='CREATED'（⚠W3-12）——成团链/终态场次无法露出（详情端点任意态可见已实证）；②报名/成团链无通知生产方（EnrollmentPaid/SessionFull 消费方仅 metrics）——用户收不到报名回执/成团通知；③通知无已读位/端点；④我发起的拼团历史不可见（无 mine/详情端点，PUBLISHED 窗口外消失+发起人无 enrollment 行）；⑤/enrollments/mine 无场次上下文字段（前端补拉降级承载）；⑥偏好无模板目录枚举端点（stale 行 PUT 404 理论死锁）；⑦core 无 CORS 装配（dev 跨端口需反代——E2E 已解；生产=同域部署或 core 补 CORS，随 M5 部署批拍板）。
