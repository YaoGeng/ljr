## 1. 摘要（关键数字一览）

| 问题 | 答案 |
|---|---|
| 生产能不能放海外 | **不能**。ICP/EDI 备案要求境内服务器；PIPL 数据不出境；等保二级测评对象是境内系统（架构 §1.3-5/§1.3-7）。海外节点仅限开发/测试/CI，且不得承载任何真实用户个人信息 |
| 国内生产一个月多少钱 | **staging/上线初期 ¥200-250/月；生产合规档 ¥700-1,000/月**（双机 + RDS 高可用 + Tair + OSS）；成长期 ¥2,500-4,000/月 |

## 2. 前提与硬约束（为什么这样选）

1. **生产必须境内**（不可协商）：域名 ICP 备案绑定境内服务器是 EDI 许可证与 App 备案的前置（05 §9 上线门禁）；用户手机号/实名/聊天记录均属个人信息，出境触发 PIPL 评估（架构 §1.3-5）；等保二级测评对象为境内系统。香港节点虽免备案、延迟好，但个人信息放香港同样构成出境，**V1 不碰**。
2. **负载画像（架构 §1.2）**：V1 北京单城、日活千级、并发房间百级；Core API 99.9% 可用性要求。该负载在 2×4C8G + RDS 2C4G 规格内绰绰有余——**V1 的成本敏感点不在算力，在合规与可用性档位选择**。
3. **服务形态（架构 §2.2/§7.1）**：模块化单体 Core（含调度器，与 Core 同进程）+ rtc-im（WSS 网关）+ agent-assist + payment-gateway 三个独立服务；PG15 + Redis + RocketMQ（可后置，见 D-P4）+ OSS；音视频走声网 SaaS（无服务器成本，按量 ¥7/千分钟已计入 06 变动成本）。
4. **等保过测策略**：云上 RDS/Tair 可直接复用云平台的等保备案结论，自建数据库则需自行应对测评中的数据库安全项——**这是「省机器钱自建 PG」vs「买 RDS」的真实权衡，不只是价格**。

## 3. 国内方案（生产，分四档）

### 3.1 档位表

| 档位 | 阶段 | 配置 | 月成本 | 年成本 |
|---|---|---|---|---|
| **D0 开发期** | 现状 → M5 前 | 本机 portable PG（现状，¥0）+ 海外 dev/CI（§4） | ~¥125 | ~¥1,500 |
| **D1 staging/上线初期** | M5 前后，等保测评对象 | 轻量 4C8G ×1（活动价 ~¥446/年）+ RDS PG **基础**系列 2C4G（新用户 ¥228/年首年，常规 ~¥124/月）+ Tair 256MB（¥72/年）+ OSS 100GB 包（~¥99/年） | **~¥200-250** | **~¥3,000** |
| **D2 生产合规档** | 正式运营（抽佣启动、真实用户） | ECS 4C8G ×2（u1 经济型活动价 ~¥1,252/年/台）+ RDS PG **高可用** 2C4G 50GB（~¥348/月，一主一备）+ Tair 1GB 主从（~¥68-170/月 ⚠ 活动价与标准价差异大）+ OSS 500GB 包（~¥118/年）+ CDN 按量 | **~¥700-1,000** | **~¥8,500-12,000** |
| **D3 成长期** | M13+，月 GMV >¥10 万 | PG 升 4C8G 高可用 + 只读副本；ECS 升配/加节点；RocketMQ 独立部署 | ¥2,500-4,000 | ¥30,000-48,000 |

> D3 即 06 §2.2 原假设档位——原假设对应的是成长期而非 V1 初期。

### 3.2 档位升档触发条件（避免提前升档烧钱）

| 升档 | 触发信号 |
|---|---|
| D1 → D2 | 等保测评通过 + ICP/EDI 就绪、准备接真实用户流量（**合规事件驱动，不是负载驱动**） |
| D2 → D3 | 满足任一：CPU 峰值持续 >60%；PG 连接数/慢查询告警；月 GMV >¥10 万；房间并发 >300（V1 设计上限百级，留 3 倍余量） |

### 3.3 部署拓扑（D2 生产合规档）

```
ECS-1 (4C8G)                    ECS-2 (4C8G)
├─ core（含 TS 调度器）×2 副本    ├─ core（调度器多节点 SKIP LOCKED 天然去重）
├─ rtc-im（WSS 网关）            ├─ rtc-im（≥2 节点，房间态 Redis+DB 可重建）
├─ agent-assist                 ├─ agent-assist
└─ payment-gateway              └─ payment-gateway
        │                               │
RDS PG15 高可用（一主一备）   Tair/Redis（缓存/限流/房间成员态）
OSS（聊天冷存/录音存证 WORM bucket，3 年留存）
CDN（App 静态资源/图片）      SLB 或 DNS 轮询（V1 可先 DNS 轮询省 SLB ¥）
```

- RocketMQ：V1 先用 PG Outbox + 轮询 relay 起步（架构已定义 Outbox 为事实源，MQ 仅低延迟优化），D3 再上——省一台中间件机器与运维面（D-P4）。
- 备份：RDS 自动快照（含在 RDS 价格内）+ OSS 跨区域复制的周全量；等保要求日志留存 ≥6 个月（网安法 §21），云日志服务按量（量小，~¥10-30/月）。

### 3.4 省钱细节

- **轻量 vs ECS**：同规格轻量约为 ECS 标准型 3 折（4C8G：¥446 vs ¥1,437/年），但活动价限新用户/限购、部分高级特性（VPC 对连接、多网卡）受限。策略：staging 用轻量，prod 用 ECS 活动价。
- **先做企业实名认证再采购**：后续 ICP 备案、微信收付通进件、等保备案全用同一主体；企业账号另有代金券与免费试用额度（腾讯云企业可免费试用 4C8G）。
- **Redis 起步不必买云产品**：V1 用途是缓存/限流/房间成员态，应用机上 Docker 自建 = ¥0；等保前再上 Tair 256MB（¥72/年，一杯咖啡钱消除一个测评问答项）。
- **续费才是真实成本**：活动机 3 年期口径下，第 2-3 年按原价（轻量 4C8G ~¥1,500/年）计——**3 年总持有成本 ≈ 首年价 ×2.5** ⚠。腾讯有老用户同价续费政策、阿里有 99 元续费类似款，下单前确认条款。

## 8. 三方服务接入盘点（v1.1 增补）

对照架构 §2.2/§2.3 与模块规格全量盘点运行时三方依赖：**已选型 4 件**（M0 选型报告：LLM=智谱、实名=腾讯云三要素、RTC=声网、支付=微信收付通+支付宝直付通）+ **本次补研 3 件**（短信、App 离线推送、存证上链——对应 I1-通知中心「SMS/厂商通道聚合」与 I3-文件与存证存储「存证平台」的规格留白）+ 可选/待澄清 5 件。补研检索时点同 §9（2026-10-17）。

> **v1.2 注记（2026-10-18 决策人拍板，04 §8 #40；v1.3 修正收款主体）**：上表「支付=微信收付通+支付宝直付通」为**公开上线期目标形态**（**v1.6：先行实现已拍板=汇付斗拱延时分账——聚合单 API 覆盖微信/支付宝，收付通/直付通保留迁移位，04 §8 #41**）——测试期（真实环境）收款=**单一测试收款账号（管理员持有的商家收款账号）+admin 核对账单人工确认**（平台配置收款信息，用户付款至该账号，确认驱动 PAID；测试期资金=测试性质由管理员人工处置，真实经营性律师费流转开始前必须切律师直收或收付通——二清边界，04 §8 #40 修正后口径），工程承载=人工确认通道适配器（manual-test；**v1.4 时点修正：施工自 M2 后置至 M5 支付真实化段 M5-6b**，M2~M4 开发期支付交互=直接成功口径——04 §8 #40 同日三次修正）；收付通进件与 ICP/EDI 证照全套推迟至公开上线前启动（§3.2 升档条件中「ICP/EDI 就绪」的触发时点随之后移；§3.4 采购提示中「企业实名→收付通进件」链条同为公开上线期动作）。

### 8.1 补研三件：结论与成本

| 服务 | 用途（模块） | 推荐 | 备选 | 价格 | 前置与周期 |
|---|---|---|---|---|---|

**推送的架构注记**：App 在线时走自研 WSS 长连接（rtc-im）自有通道，离线才依赖厂商通道——到点提醒另有 SMS 兜底，且调度事实源在 DB（触达 ≠ 判定），**免费方案不伤正确性**。极光免费版每次推送仅约 30% 用户可走厂商通道、离线消息只存 5 条/约 1 天，对「到点履约」强提醒是硬伤，故 V1 直接自接而非用免费聚合；付费聚合（¥3,000/月）相当于 D2 档全部服务器费用的一半，日活破万前无必要。
